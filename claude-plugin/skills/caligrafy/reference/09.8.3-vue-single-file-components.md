# 9.8.3 Single File Components

> Source: Caligrafy Quill wiki - https://github.com/caligrafy/caligrafy-quill/wiki/9.8.3-Single-File-Components
> Bundled with the caligrafy-quill Claude plugin. Content preserved from the wiki; formatting cleaned.

A **single file component** is one `.vue` file that holds a piece of the screen: its markup (`<template>`), its behaviour (`<script>`) and, when it needs one, its style (`<style>`). Vite turns these files into the built app. In a Caligrafy single page app, the screens of the router are **page** components (`src/components/pages/`), and pieces used on several screens are **global** components (`src/components/global/`). A parent passes data down through **props** and hears from a child through **events**.

## With Claude

Ask for the piece and who uses it: "in shelfapp, make the add form a component BookForm that shows the errors the page gives it and sends the book to the page; after adding, open the new book". Claude writes `src/components/global/BookForm.vue` and changes `src/components/pages/BooksPage.vue`.

**Check** before you say OK:
+ The child declares its `props` and `emits`; it never changes a prop.
+ Only page components (or the store) call the capabilities.
+ The markup uses the page components (`.cq-form-grid`, `.cq-field`, `.cq-field-error`), with no `<style>` for what they already do.
+ `npm run build` ends with `✓ built`.

## By hand

You add a form component to the Bookshelf app of [Routing for single page apps](https://github.com/caligrafy/caligrafy-quill/wiki/9.8.2-Routing-for-Single-Page-Applications). Files are in `public/shelfapp/`.

**1. The child.** Write `src/components/global/BookForm.vue`:
```vue
<template>
	<form method='POST' novalidate @submit.prevent='submit'>
		<div class='cq-form-grid cq-form-grid--2'>
			<div class='cq-field'>
				<label for='title'>Title</label>
				<input id='title' class='form-control' type='text' maxlength='200' v-model.trim='book.title'>
				<p class='cq-field-error' v-if='errors.title'>{{ errors.title }}</p>
			</div>
			<div class='cq-field'>
				<label for='author_id'>Author</label>
				<select id='author_id' class='form-select' v-model.number='book.author_id'>
					<option v-for='author in authors' :key='author.id' :value='author.id'>{{ author.name }}</option>
				</select>
				<p class='cq-field-error' v-if='errors.author_id'>{{ errors.author_id }}</p>
			</div>
			<div class='cq-field'>
				<label for='published_year'>Year</label>
				<input id='published_year' class='form-control' type='number' v-model.number='book.published_year'>
				<p class='cq-field-error' v-if='errors.published_year'>{{ errors.published_year }}</p>
			</div>
			<div class='cq-field'>
				<label for='summary'>Summary</label>
				<input id='summary' class='form-control' type='text' maxlength='2000' v-model.trim='book.summary'>
			</div>
		</div>
		<button class='btn btn-primary' type='submit'>Add book</button>
	</form>
</template>

<script>
export default {
	name: 'book-form',
	props: {
		authors: { type: Array, default: () => [] },
		errors: { type: Object, default: () => ({}) }
	},
	emits: ['add'],
	data() {
		return { book: { title: '', author_id: null, published_year: null, summary: '' } }
	},
	methods: {
		submit() {
			this.$emit('add', { ...this.book })
		}
	}
}
</script>
```
It keeps what is typed, lists the `authors` and shows the `errors` its parent passes, and sends a copy of the book with the `add` event.

**2. The parent.** Replace `src/components/pages/BooksPage.vue` with:
```vue
<template>
	<main>
		<section class='cq-hero cq-hero--page'>
			<h1 class='cq-display'>Books</h1>
			<p class='cq-lead'>{{ total }} books on the shelf.</p>
		</section>
		<section class='cq-band cq-band--tight'>
			<div class='cq-inner cq-inner--narrow'>
				<p class='cq-alert cq-alert--error' role='alert' v-if='error'>{{ error }}</p>
				<book-form :authors='authors' :errors='errors' @add='addBook'></book-form>
				<ul class='cq-rows' v-if='books.length'>
					<li class='cq-row' v-for='book in books' :key='book.id'>
						<div class='cq-row-main'>
							<p class='cq-row-title'>
								<router-link :to='{ name: "book", params: { id: book.id } }'>{{ book.title }}</router-link>
							</p>
							<p class='cq-row-meta'>{{ book.author.name }}, {{ book.published_year }}</p>
						</div>
					</li>
				</ul>
				<p class='cq-empty-state' v-else>No books yet: add the first one above.</p>
			</div>
		</section>
	</main>
</template>

<script>
import { listBooks, listAuthors, createBook, CapabilityError } from '@/capabilities.js'
import BookForm from '../global/BookForm.vue'

export default {
	name: 'books-page',
	components: {
		'book-form': BookForm
	},
	data() {
		return { books: [], total: 0, authors: [], errors: {}, error: '' }
	},
	async mounted() {
		try {
			this.authors = await listAuthors()
			const page = await listBooks({ page: 1 })
			this.books = page.data
			this.total = page.total
		} catch (e) {
			this.error = e.message
		}
	},
	methods: {
		async addBook(book) {
			this.errors = {}
			this.error = ''
			try {
				const created = await createBook(book)
				this.$router.push({ name: 'book', params: { id: created.id } })
			} catch (e) {
				if (e instanceof CapabilityError && e.code === 'invalid') this.errors = e.fields
				else this.error = e.message
			}
		}
	}
}
</script>
```

**3. Try it.** Run `npm run dev` and open `http://localhost:5173/#/` (or `npm run build` and `http://localhost:8080/public/shelfapp/dist/index.html`):
+ Type `Mind of My Mind`, choose Octavia E. Butler, no year, press **Add book**: `The Published Year field is required` under the year; the title stays.
+ Type `1977` and press **Add book**: the address becomes `#/books/6` and the page shows *Mind of My Mind*, `by Octavia E. Butler, 1977`.

**Check**
+ `BookForm.vue` imports nothing from `capabilities.js`.
+ `npm run build` ends with `✓ built`.

## Reference

### The parts of a `.vue` file

| Part | What it holds |
| --- | --- |
| `<template>` | the markup, with Vue's syntax (`{{ }}`, `v-if`, `v-for`, `v-model`, `:prop`, `@event`) |
| `<script>` | `export default { name, components, props, emits, data(), computed, watch, mounted(), methods }`, and the `import`s it needs |
| `<style>` | its own CSS when the page components do not cover it; `<style scoped>` keeps it to this component |

`@` is the `src/` folder (the alias of `vite.config.js`): `import BookForm from '@/components/global/BookForm.vue'`.

### Kinds of components

| Kind | Where | Example |
| --- | --- | --- |
| frame | `src/App.vue` | the top bar, `<router-view>`, the footer |
| page | `src/components/pages/` | `BooksPage.vue`, `BookPage.vue`: named by the routes |
| global | `src/components/global/` | `ShowNavigation.vue`, `BookForm.vue`: used by several pages |

### Talking between components

| Direction | How |
| --- | --- |
| parent to child | props: `props: { errors: { type: Object, default: () => ({}) } }` in the child, `<book-form :errors="errors">` in the parent |
| child to parent | events: `emits: ['add']` and `this.$emit('add', book)` in the child, `<book-form @add="addBook">` in the parent (the method gets `book`) |
| markup from the parent | slots: `<slot></slot>` in the child's template |
| between any components | a store ([State management](https://github.com/caligrafy/caligrafy-quill/wiki/9.8.4-State-Management)) |

Vue's guides: [single file components](https://vuejs.org/guide/scaling-up/sfc.html), [props](https://vuejs.org/guide/components/props.html), [events](https://vuejs.org/guide/components/events.html), [slots](https://vuejs.org/guide/components/slots.html).

## Other ways

+ **The Composition API** (`<script setup>`): the same component written with `defineProps`, `defineEmits` and `ref`:
  ```vue
  <script setup>
  import { ref } from 'vue'
  defineProps({
    authors: { type: Array, default: () => [] },
    errors: { type: Object, default: () => ({}) }
  })
  const emit = defineEmits(['add'])
  const book = ref({ title: '', author_id: null, published_year: null, summary: '' })
  function submit() { emit('add', { ...book.value }) }
  </script>
  ```
  The template is the same. Pick one style per app; this wiki uses the Options API of the template.

## Common mistakes

+ **A component that changes its prop** (`this.errors = {}` in `BookForm`): Vue warns in development and the parent's value does not change. Send an event.
+ **Forgetting `components: { 'book-form': BookForm }`** in the parent: the tag stays unknown (a warning in `npm run dev`).
+ **An event not in `emits`**: it still works, but Vue also passes the listener to the root element; declare every event.
+ **A `<style>` that copies the page components**: use their classes, so the app keeps Caligrafy's look and its design style.
