# 9.7.0 Setting up Vue.js as a library

> Source: Caligrafy Quill wiki - https://github.com/caligrafy/caligrafy-quill/wiki/9.7.0-Setting-up-Vue.js-as-a-library
> Bundled with the caligrafy-quill Claude plugin. Content preserved from the wiki; formatting cleaned.

**Vue as a library** is the shortest way to add a Vue screen to a Caligrafy application: no Node.js, no build step. Vue 3 loads from a pinned CDN address, your markup is a `.php` file in `public/<app>/`, your script is `public/<app>/scripts/main.js`, and Caligrafy serves the page through a page route. The app reads and writes data by calling your capabilities through the generated JS client. For a larger app with its own routes and a build, see the [Vite single page app](https://github.com/caligrafy/caligrafy-quill/wiki/9.8.1---Setting-up-the-Vue-application).

## With Claude

```text
/caligrafy-quill:new-app app bookshelf
```
Then describe the screen: "a list of the books with an add form, through the books capabilities". Claude checks the name, runs `php caligrafer.php app bookshelf`, generates `public/js/capabilities.js`, adds the page route to `application/config/routing/web.php`, and writes `public/bookshelf/index.php` and `public/bookshelf/scripts/main.js` with the page components.

**Check** before you say OK:
+ The address Claude gives opens the screen, and the browser console has no error.
+ `main.js` loads `public/js/capabilities.js` and calls the capabilities by name; no `apiKey`, no `Authorization` header.
+ Adding a book without a year shows `The Published Year field is required` under the year.

## By hand

You build the Bookshelf screen at `/bookshelf`: the books, 20 a page, and a form to add one. You need the Bookshelf tables and capabilities (`list_books`, `create_book`, `list_authors`) of [Views, steps 1 to 3](https://github.com/caligrafy/caligrafy-quill/wiki/7.-Views#viewsstartup), and `Route::capabilities('/capabilities');` in `application/config/routing/web.php` (the Quickstart adds it). Commands run in the project folder with the Docker server; addresses start with `http://localhost:8080/`.

**1. Scaffold the app.** Run:
```bash
docker compose exec dev-box php caligrafer.php app bookshelf
```
Expected: `Project created in the public folder.` It copies `framework/plugins/app` to `public/bookshelf/`: `index.php` and `scripts/main.js`. The name must not be a folder Caligrafy already uses in `public/` (`app`, `bot`, `__bots__`, `css`, `facedetect`, `fonts`, `images`, `js`, `ml`, `resources`, `uploads`) and `public/bookshelf/` must not exist yet.

**2. Generate the JS client.** Run:
```bash
docker compose exec dev-box php caligrafer.php client public/js/capabilities.js
```
Expected: `public/js/capabilities.js written: <n> capabilities, calls /capabilities (Route::capabilities('/capabilities') in web.php)`. Run it again after every change to a capability.

**3. The page route.** In `application/config/routing/web.php`, above `Route::run();`, write:
```php
    // BOOKSHELF: the Vue app (public/bookshelf/index.php)
    Route::page('/bookshelf', 'Client/app', ['with' => ['appName' => 'bookshelf', 'app' => 'index']]);
```
Open `http://localhost:8080/bookshelf`: the template's screen, *My Vue app*, lists the capabilities a visitor may call (`create_book`, `get_book`, `list_books`...).

**4. The markup.** Replace `public/bookshelf/index.php` with:
```php
<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
        <title>Bookshelf</title>
        <link rel="shortcut icon" href="<?php echo scripts('favicon'); ?>" type="image/x-icon" />
        <link rel="stylesheet" href="<?php echo scripts('bootstrap_css'); ?>" />
        <link rel="stylesheet" href="<?php echo session('public').'css/theme.css';?>">
        <link rel="stylesheet" href="<?php echo session('public').'css/tokens.css';?>">
        <link rel="stylesheet" href="<?php echo session('public').'css/layout.css';?>">
        <link rel="stylesheet" href="<?php echo session('public').'css/look.css';?>">
        <?php if (design_stylesheet()): ?><link rel="stylesheet" href="<?php echo design_stylesheet(); ?>"><?php endif; ?>
    </head>

    <body class="cq-site">
        <div id="app" v-cloak>
            <nav class="cq-nav" aria-label="Main">
                <a class="cq-nav-brand" :href="env.home"><img class="cq-nav-mark" :src="env.home + 'public/images/resources/caligrafy-mark.svg'" alt="" width="28" height="28"><span class="semibold">Book</span>shelf</a>
            </nav>
            <section class="cq-hero cq-hero--page">
                <h1 class="cq-display">Books</h1>
                <p class="cq-lead">{{ total }} books on the shelf.</p>
            </section>
            <section class="cq-band cq-band--tight">
                <div class="cq-inner cq-inner--narrow">
                    <p class="cq-alert cq-alert--error" role="alert" v-if="error">{{ error }}</p>
                    <form method="POST" novalidate @submit.prevent="addBook">
                        <div class="cq-form-grid cq-form-grid--2">
                            <div class="cq-field">
                                <label for="title">Title</label>
                                <input id="title" class="form-control" type="text" maxlength="200" v-model="book.title">
                                <p class="cq-field-error" v-if="errors.title">{{ errors.title }}</p>
                            </div>
                            <div class="cq-field">
                                <label for="author_id">Author</label>
                                <select id="author_id" class="form-select" v-model.number="book.author_id">
                                    <option v-for="author in authors" :key="author.id" :value="author.id">{{ author.name }}</option>
                                </select>
                                <p class="cq-field-error" v-if="errors.author_id">{{ errors.author_id }}</p>
                            </div>
                            <div class="cq-field">
                                <label for="published_year">Year</label>
                                <input id="published_year" class="form-control" type="number" v-model.number="book.published_year">
                                <p class="cq-field-error" v-if="errors.published_year">{{ errors.published_year }}</p>
                            </div>
                            <div class="cq-field">
                                <label for="summary">Summary</label>
                                <input id="summary" class="form-control" type="text" maxlength="2000" v-model="book.summary">
                            </div>
                        </div>
                        <button class="btn btn-primary" type="submit">Add book</button>
                    </form>
                    <ul class="cq-rows" v-if="books.length">
                        <li class="cq-row" v-for="item in books" :key="item.id">
                            <div class="cq-row-main">
                                <p class="cq-row-title">{{ item.title }}</p>
                                <p class="cq-row-meta">{{ item.author.name }}, {{ item.published_year }}</p>
                            </div>
                        </li>
                    </ul>
                    <p class="cq-empty-state" v-else>No books yet: add the first one above.</p>
                    <p v-if="pages > 1">
                        <button class="btn btn-secondary" type="button" :disabled="page === 1" @click="load(page - 1)">Previous</button>
                        <button class="btn btn-secondary" type="button" :disabled="page === pages" @click="load(page + 1)">Next</button>
                    </p>
                </div>
            </section>
        </div>

        <script src="<?php echo scripts('vue'); ?>"></script>
        <script src="<?php echo APP_SERVICE_ROOT.'app.js'; ?>"></script>
        <script>loadEnvironment(`<?php echo $env; ?>`);</script>
        <script>loadVue({ scripts: ['main'] });</script>
    </body>
</html>
```

**5. The script.** Replace `public/bookshelf/scripts/main.js` with:
```js
// Bookshelf: the books of the catalog, through the generated JS client (public/js/capabilities.js)
const app = Vue.createApp({
    data () {
        return {
            env: env,
            books: [], total: 0, page: 1, pages: 1,
            authors: [],
            book: { title: '', author_id: null, published_year: null, summary: '' },
            errors: {},
            error: ''
        }
    },
    async mounted () {
        this.api = await import(env.home + 'public/js/capabilities.js')
        this.api.configure({ baseUrl: env.home.replace(/\/$/, '') })   // the application root, whatever APP_ROOT is
        this.authors = await this.api.listAuthors()
        await this.load(1)
    },
    methods: {
        async load (page) {
            const result = await this.api.listBooks({ page: page })   // { data, total, page, per_page, pages }
            this.books = result.data
            this.total = result.total
            this.page = result.page
            this.pages = result.pages
        },
        async addBook () {
            this.errors = {}
            this.error = ''
            try {
                await this.api.createBook(this.book)
                this.book = { title: '', author_id: null, published_year: null, summary: '' }
                await this.load(1)
            } catch (e) {
                if (e.name === 'CapabilityError' && e.code === 'invalid') this.errors = e.fields
                else this.error = e.message
            }
        }
    }
})

app.mount('#app')
```

**6. Try it.** Reload `http://localhost:8080/bookshelf`:
+ The title band says `5 books on the shelf.`, the list shows them sorted by title (`Ursula K. Le Guin, 1968` under *A Wizard of Earthsea*), and the Author list holds the three authors.
+ Type `Dawn`, choose Octavia E. Butler, leave the year empty, press **Add book**: `The Published Year field is required` appears under the year, and the title stays.
+ Type `1987` and press **Add book**: the count says `6 books on the shelf.`, *Dawn* is in the list, and the fields are empty.

**Check**
+ The browser console shows no error other than the `422` of the refused book, and the network panel shows `POST /capabilities/list_authors`, `list_books` and `create_book`, each with an `X-CSRF-Token` header.
+ The page source contains no API key in `main.js` and no `Authorization` header is sent.
+ At phone width the two fields stack and the rows stay readable.

## Reference

| What | Value |
| --- | --- |
| Command | `php caligrafer.php app <name>` (or `.bin/caligrafer app <name>`): copies `framework/plugins/app` to `public/<name>/` |
| Files | `public/<name>/index.php` (the markup: a `.php` file, so it can use Caligrafy's helpers), `public/<name>/scripts/main.js` (loaded by `loadVue({ scripts: ['main'] })`) |
| Vue | `scripts('vue')`: Vue 3.5.44, the global production build from jsDelivr, pinned in `framework/settings/coresettings.php` |
| Page route | `Route::page('<path>', 'Client/app', ['with' => ['appName' => '<name>', 'app' => 'index']])`, or the ready-made `/apps/<name>` ([Routes](https://github.com/caligrafy/caligrafy-quill/wiki/9.7.2-Routes)) |
| JS client | `php caligrafer.php client public/js/capabilities.js`; loaded with `await import(env.home + 'public/js/capabilities.js')` because `main.js` is a classic script ([Requests](https://github.com/caligrafy/caligrafy-quill/wiki/9.7.3-Requests#capabilities)) |
| Stylesheets | `theme.css`, `tokens.css`, `layout.css`, `look.css` and the design style, as in the template; `body.cq-site` and the page components |

`configure({ baseUrl })` matters when the application is not at the root of its address (`APP_ROOT` not empty, for example `http://localhost:8888/myapp/` with MAMP): without it the client calls `/capabilities` at the root of the server.

## Other ways

+ **The template's own screen.** Before step 4, the template lists the capabilities the visitor may call (`await this.api.capabilities()`): use it to see what a visitor or a signed-in user may do.
+ **Copying the template yourself.** Without PHP on the computer, `cp -r framework/plugins/app public/bookshelf` is what the command does.

## Common mistakes

+ **Running `app <name>` for a folder that exists**: the template is copied inside it, as `public/<name>/app/`. Pick a new name.
+ **`import` at the top of `main.js`**: it is a classic script; load the client with `await import(...)` inside `mounted()`.
+ **The client file is missing**: the template's screen says `The JS client is missing`, and your own script stops with a failed import in the console. Run step 2.
+ **A capability added later is not in the client**: run step 2 again.
+ **`Bearer ' + apiKey` in old scripts**: the legacy key is public and turned off on Caligrafy Cloud (`LEGACY_API_KEY=false`): call the capabilities through the client.
