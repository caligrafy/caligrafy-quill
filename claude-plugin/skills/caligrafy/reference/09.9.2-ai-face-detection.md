# 9.9.2 Face Detection and Face Recognition

> Source: Caligrafy Quill wiki - https://github.com/caligrafy/caligrafy-quill/wiki/9.9.2-Face-Detection-and-Face-Recognition
> Bundled with the caligrafy-quill Claude plugin. Content preserved from the wiki; formatting cleaned.

> **Verified against framework source (see gotchas.md):**
> - `face-api.min.js` is @vladmandic/face-api 1.7.15 with its own models in `public/resources/models` (no MTCNN). Wrap the detector in `Vue.markRaw(new FaceDetector('detection'))` and `await detector.ready` before recognition (G16, G42).

**FaceDetect** finds faces in a camera, a video or a picture, and recognizes whose face it is, in the browser. It is a
JavaScript class, `FaceDetector` (`public/js/services/detect.js`), built on
[@vladmandic/face-api](https://github.com/vladmandic/face-api) 1.7.15 (the maintained successor of face-api.js) and
its TensorFlow.js models, which ship with Caligrafy in `public/resources/models`. The pictures never leave the browser
unless your code sends them. `FaceDetector` also gives face prints and a liveness check, which the server-side class
`Caligrafy\FaceLogin` uses for [face sign-in](#face-login).

In the Bookshelf example, a page checks that the photo of a library card shows exactly one face.

> #### (video) [Detecting and Recognizing human faces with Caligrafy](https://youtu.be/uUcr6JM00S4)
>
> The video shows how the FaceDetect library detects and recognizes faces.


Claude checks the name, runs `docker compose exec dev-box php caligrafer.php facedetect faces`, and gives you the address of the app
(`/apps/faces`). Then describe what the app should do: *"a page that checks that a library card photo has exactly one
face"*, or *"face sign-in with liveness and passkeys"*, for which Claude follows the plugin's face login recipe.

**Check**
- The detector is created with `Vue.markRaw(new FaceDetector('detection'))` in a Vue app.
- The markup keeps `#detector`, the media with `id="detection"`, `#apps` and `#infobar`.
- A blocked or missing camera is told to the person (`{ autoStart: false }` and `startStream()` in a `try`).
- Face sign-in is never one face print: it uses the server challenge, `liveness()` and `FaceLogin::verify()`, and
  offers a passkey.

`loadVue({ scripts: [...] })` adds `public/faces/scripts/<name>.js` to the page (with or without Vue). Create
**`public/faces/scripts/cardphoto.js`**:

```js
// Checks that a library card photo shows exactly one face, in the browser: the photo is not sent anywhere
const detector = new FaceDetector('detection');   // an <img>: no camera
const image = document.getElementById('detection');
const result = document.getElementById('result');

detector.ready.then(() => { result.textContent = 'Choose a photo of your face.'; });

document.getElementById('file').addEventListener('change', (event) => {
    const file = event.target.files[0];
    if (!file) return;
    result.textContent = 'Checking...';
    image.onload = async () => {
        image.hidden = false;
        try {
            const print = await detector.faceprint(image);
            result.textContent = 'Good photo: one face, ' + Math.round(print.detection.score * 100) + '% sure.';
        } catch (error) {
            // 'No face found' or 'More than one face found'
            result.textContent = error.message + ': choose another photo.';
        }
    };
    image.src = URL.createObjectURL(file);
});
```

Open `http://localhost:8080/apps/faces?app=cardphoto`. The text changes to *Choose a photo of your face.* when the
models are loaded. Choose a portrait: *Good photo: one face, 99% sure.* Choose a picture with no face: *No face found:
choose another photo.*

### Step 4: Recognize your own people

1. Create one folder per person in `public/faces/recognition/`, named after them, with PNG pictures named `1.png`,

2. In `public/faces/scripts/main.js`, change the **Recognize** app:

```js

    name: 'Recognize',
    method: this.detector.recognize,
    models: {
        labels: ['Flash', 'Ada'],   // the folder names
        sampleSize: 4               // pictures per person
    },
    options: {
        welcome: 'Show your face',
        recognition: true
    },
    algorithm: faceapi.SsdMobilenetv1Options

```

Reload `/apps/faces` and click **Recognize**: a box with the name and the distance (`Ada (0.41)`) follows each known
face, `unknown` the others. A picture in which no face is found is skipped, so use clear, front-facing portraits.

**Check**
- `/apps/faces` shows the six buttons and the camera (or the blocked-camera message).
- `?app=cardphoto` answers *Good photo* for one face and *No face found* / *More than one face found* otherwise.

### `new FaceDetector(media, options = {})`

`media` is the id of the `<video>`, `<img>` or `<canvas>`. The models start loading at once; `detector.ready` is a
promise that resolves when they are loaded. With `options.autoStart` (default `true`) and a `<video>` without a
source, the camera starts once the models are loaded. In a Vue 3 app, wrap it in `Vue.markRaw()` before putting it in
`data`: otherwise Vue wraps the canvases, streams and models in reactive proxies, which slows or breaks the detections.

```js
var detector = Vue.markRaw(new FaceDetector('detection'));
```

### Controlling the camera

To tell the person when the camera is blocked or missing, create the detector with `{ autoStart: false }` and start
the camera yourself. `startStream()` rejects with the browser's error: `NotAllowedError` (blocked), `NotFoundError`
(no camera); the error is also in `detector.streamError`.

```js
var detector = Vue.markRaw(new FaceDetector('detection', { autoStart: false }));

// in a Vue method: the promise waits for as long as the person takes to answer the permission prompt
async startCamera() {
    try {
        await detector.startStream({ video: { facingMode: 'user' }, audio: false });  // getUserMedia constraints
    } catch (error) {
        this.message = error.name === 'NotAllowedError' ? 'Allow camera access, then retry' : 'No camera found';
    }
}

detector.stopStream(); // turns the camera off
```

The buttons of `loadApp()` appear at once and work as soon as the models are loaded.

### Face prints

`faceprint(media = null, minConfidence = 0.6)` returns the face print of the only face in the media:
`{ descriptor: [128 numbers], detection }` (the detection has `score` and `box`). It rejects with `No face found` or
`More than one face found`. Two prints of the same person are usually closer than 0.5
(`faceapi.euclideanDistance(a, b)`), prints of different people further than 0.6.

```js
await detector.ready;
const print = await detector.faceprint();            // the detector's media
const other = await detector.faceprint(someImage);   // any <img>, <video> or <canvas>
faceapi.euclideanDistance(print.descriptor, other.descriptor) < 0.5;  // probably the same person
```

A single face print is not a sign-in: a photo held to the camera gives one, and a print sent once can be sent again.

### Liveness

`liveness(options)` asks the person to do challenges in front of the camera and captures face prints while they move.
It follows the head turn (yaw) and the `happy` expression frame by frame: a turn starts facing the camera, a smile
starts neutral, so a photo fails.

```js
const result = await detector.liveness({
    challenges: ['turn-left', 'smile'],   // in this order; left and right are the person's own
    timeout: 20000,                       // ms for the whole check
    prints: 4,                            // face prints to capture
    onProgress: (p) => console.log(`${p.index + 1}/${p.total}: ${p.challenge}`)
});
// { passed: true, reason: null, challenges: [{ name, passed, at }], prints: [{ descriptor, challenge, at }], frames, duration }
```

| Option | Default |
|---|---|
| `challenges` | `['turn-left', 'smile']` (also `turn-right`; there is no `blink`) |
| `timeout` | `20000` ms |
| `prints` | `4`; the check passes with at least 3 (or `prints` when lower), the minimum of `FaceLogin::verify()` |
| `printInterval` | `350` ms between prints |
| `onProgress` | called with `{ challenge, index, total, passed }` when a challenge starts or passes |
| `thresholds` | overrides of `FaceDetector.LIVENESS_THRESHOLDS` = `{ frontalYaw: 0.15, turnYaw: 0.3, neutral: 0.3, smile: 0.8 }` |

It does not reject when the check fails: `passed` is `false` and `reason` says why (`Challenge not completed: smile`,
`More than one face found`, `Not enough face prints`). It rejects only when the models or the media cannot be used.
With a server challenge, keep `timeout` within its `expires_in`.

## Face login

Face sign-in uses the browser for the camera and the server for every decision. **`Route::auth` has no face option**:
face sign-in keeps a controller, and this is the template to use. The challenges come from the server, so a recording
of an earlier sign-in does not do them in the right order:

1. `POST /facelogin/start`: `FaceLogin::challenge($username)` returns a single-use nonce and 2 of the 3 challenges in a
   random order, kept in the session for 60 seconds.
2. The browser runs `detector.liveness({ challenges })` and sends `{ nonce, liveness, prints }`.
3. `POST /facelogin/login`: `FaceLogin::verify()` uses up the nonce (once, even when the check fails), requires the
   liveness result for the requested challenges in that order, and 3 to 12 prints of the same face that are **not
   identical** (identical prints are a replayed print, not a live camera). `FaceLogin::match()` then finds the account;
   prints already used by an earlier sign-in are refused.

**Honest limits.** Liveness in the browser stops photos, replayed requests and replayed prints. It does not stop a
determined attacker: a deepfake video through a virtual camera, or a modified page that sends made-up prints, can pass.
Use face sign-in as a convenience and require a [passkey](#passkeys) for sensitive accounts.

The steps need sign-in ([`Auth::authentication('User', 'users')`](https://github.com/caligrafy/caligrafy-quill/wiki/9.1-Authentication)
and its `users` table).

**1. The tables.** Create **`application/models/FaceLogin/create_db.sql`**:

```sql
-- Face login and passkeys for the users of the authentication module (users table). Safe to run more than once.
CREATE TABLE IF NOT EXISTS face_prints (
  id INT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
  user_id INT NOT NULL,
  descriptor TEXT NOT NULL,                      -- encryptDecrypt('encrypt', json) with APP_KEY, never plain
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  CONSTRAINT fk_face_prints_user_id FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- hashes of the prints of accepted logins: the same prints sent again with a new nonce are refused
CREATE TABLE IF NOT EXISTS face_login_used_prints (
  id INT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
  user_id INT NOT NULL,
  print_hash CHAR(64) NOT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  CONSTRAINT uq_face_login_used_prints_hash UNIQUE (print_hash),
  CONSTRAINT fk_face_login_used_prints_user_id FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- failures live in their own table, not on users: a change to the users row signs its owner out
CREATE TABLE IF NOT EXISTS face_login_attempts (
  id INT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
  attempt_key VARCHAR(191) NOT NULL,             -- client IP + username ('*' for 1:N)
  failures INT NOT NULL DEFAULT 0,
  locked_until DATETIME NULL,
  modified_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  CONSTRAINT uq_face_login_attempts_key UNIQUE (attempt_key)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- passkeys (Caligrafy\Passkey)
CREATE TABLE IF NOT EXISTS passkeys (
  id INT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
  user_id INT NOT NULL,
  credential_id VARCHAR(255) NOT NULL,           -- base64url
  public_key TEXT NOT NULL,                      -- PEM
  sign_count INT UNSIGNED NOT NULL DEFAULT 0,
  name VARCHAR(64) NOT NULL DEFAULT 'Passkey',
  transports VARCHAR(255) NULL,
  aaguid CHAR(32) NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  last_used_at DATETIME NULL,
  CONSTRAINT uq_passkeys_credential_id UNIQUE (credential_id),
  CONSTRAINT fk_passkeys_user_id FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**3. The controllers.** **`application/controllers/FaceLogin/FaceLoginController.php`**:

```php
<?php

use Caligrafy\Controller;
use Caligrafy\Database;
use Caligrafy\Auth;
use Caligrafy\FaceLogin;
use Caligrafy\FaceLoginException;
use Caligrafy\Passkey;

/**
 * Face login with a liveness check (FaceDetector.liveness() + Caligrafy\FaceLogin) for the users of the
 * authentication module. Enrolment: a password sign-in (or a new account) first, then a liveness check.
 * Login: a liveness check (the challenges chosen by start()), then the face is matched.
 */
class FaceLoginController extends Controller {
    const MAX_FAILURES = 5;
    const LOCK_SECONDS = 60;
    // what face login does for accounts that have a passkey:
    //   'face'    face alone logs in (convenience)
    //   'step-up' face, then the passkey (2 factors) - recommended for sensitive accounts
    //   'passkey' face login refused: the account logs in with its passkey only
    const PASSKEY_POLICY = 'step-up';
    const PENDING = '__face_pending';      // face checked, passkey expected

    private function fail($code, $message) { http_response_code($code); return api(['error' => $message]); }

    // lockout after MAX_FAILURES (kept outside users): [locked?, function($code, $message) recording a failure]
    private function guard($key) {
        $now = gmdate('Y-m-d H:i:s');
        $attempt = Database::toArray(Database::execute('SELECT * FROM face_login_attempts WHERE attempt_key = ?', [$key]))[0] ?? null;
        $locked = $attempt && $attempt['locked_until'] && $attempt['locked_until'] > $now;
        $failed = function ($code, $message) use ($attempt, $key, $now) {
            $failures = ($attempt && (!$attempt['locked_until'] || $attempt['locked_until'] <= $now) ? (int)$attempt['failures'] : 0) + 1;
            $lock = $failures >= self::MAX_FAILURES ? gmdate('Y-m-d H:i:s', time() + self::LOCK_SECONDS) : null;
            Database::execute('INSERT INTO face_login_attempts (attempt_key, failures, locked_until, modified_at) VALUES (?, ?, ?, ?)
                               ON DUPLICATE KEY UPDATE failures = VALUES(failures), locked_until = VALUES(locked_until), modified_at = VALUES(modified_at)',
                              [$key, $lock ? 0 : $failures, $lock, $now]);
            return $this->fail($code, $message);
        };
        return [$locked, $failed];
    }

    private function signIn($user, $factors) {
        session_regenerate_id(true);                              // new session id on every login (fixation)
        Auth::authorize($user);
        return api(['user' => ['username' => $user->username], 'factors' => $factors, 'enrolled' => count($this->enrolled((int)$user->id)) > 0]);
    }

    private function username($p) {
        $username = trim((string)($p['username'] ?? ''));
        return $username === '' || preg_match('/^[A-Za-z0-9._@-]{1,100}$/', $username) ? $username : null;
    }

    private function enrolled($userId = null) {    // [['user' => id, 'descriptor' => [128]], ...]
        $sql = 'SELECT user_id, descriptor FROM face_prints' . ($userId ? ' WHERE user_id = ?' : '');
        $rows = Database::toArray(Database::execute($sql, $userId ? [$userId] : [])) ?: [];
        return array_map(fn($r) => ['user' => (int)$r['user_id'], 'descriptor' => json_decode(encryptDecrypt('decrypt', $r['descriptor']), true)], $rows);
    }

    // POST /facelogin/start { username? } -> { nonce, challenges, expires_in }
    public function start() {
        $p = $this->request->parameters();
        if (!empty($p['enroll'])) {                               // enrolment: the logged-in account
            return authorized() ? api(FaceLogin::challenge(user()->username)) : $this->fail(401, 'Log in with your password first');
        }
        $username = $this->username($p);
        if ($username === null) { return $this->fail(422, 'Invalid username'); }
        return api(FaceLogin::challenge($username));
    }

    // POST /facelogin/enroll { nonce, liveness, prints } - logged-in users only
    public function enroll() {
        if (!authorized()) { return $this->fail(401, 'Log in with your password first'); }
        $user = user();
        try {
            $prints = FaceLogin::verify($this->request->parameters(), $user->username);
        } catch (FaceLoginException $e) {
            return $this->fail($e->getCode(), $e->getMessage());
        }
        if (FaceLogin::enrolledElsewhere($prints, $this->enrolled(), $user->id) !== null) {
            return $this->fail(409, 'This face is already enrolled on another account');
        }
        Database::execute('DELETE FROM face_prints WHERE user_id = ?', [$user->id]);
        foreach (array_slice($prints, 0, 5) as $print) {
            Database::execute('INSERT INTO face_prints (user_id, descriptor) VALUES (?, ?)', [$user->id, encryptDecrypt('encrypt', json_encode($print))]);
        }
        http_response_code(201);
        return api(['enrolled' => min(5, count($prints))]);
    }

    // POST /facelogin/password { username, password } - password sign-in before enrolment
    public function password() {
        $p = $this->request->parameters();
        $username = $this->username($p);
        if (!$username) { return $this->fail(422, 'Enter a valid username'); }
        $key = 'pw|' . ($_SERVER['REMOTE_ADDR'] ?? '') . '|' . strtolower($username);
        [$locked, $failed] = $this->guard($key);
        if ($locked) { return $this->fail(429, 'Too many failed attempts: wait a minute'); }
        $user = (new User('users'))->findByUsername($username);
        if (!$user) {
            // same work as a real check so that response times do not reveal which usernames exist
            password_verify((string)($p['password'] ?? ''), '$2y$10$B0NLUgDUK3CbImwrVfa/FuOtSOKrb7DZTGG3USPSF4Comn4cy5RtG');
        }
        if (!$user || !$user->verifyPassword((string)($p['password'] ?? ''))) {
            return $failed(401, 'Invalid username or password');
        }
        Database::execute('DELETE FROM face_login_attempts WHERE attempt_key = ?', [$key]);
        return $this->signIn($user, ['password']);
    }

    // POST /facelogin/register { username, password } - creates the account and signs it in, ready to enrol
    // (the rules of the authentication module's /register: letters and digits, passwords of 8 to 72 characters)
    public function register() {
        $p = $this->request->parameters();
        $username = trim((string)($p['username'] ?? ''));
        $password = (string)($p['password'] ?? '');
        if (!preg_match('/^[A-Za-z0-9]{1,100}$/', $username)) { return $this->fail(422, 'Usernames use letters and digits (up to 100)'); }
        if (strlen($password) < 8 || strlen($password) > 72) { return $this->fail(422, 'Passwords need 8 to 72 characters'); }
        $users = new User('users');
        if ($users->findByUsername($username)) { return $this->fail(409, 'This username is taken'); }
        Database::execute('INSERT INTO users (username, passcode) VALUES (?, ?)', [$username, User::hashPassword($password)]);
        http_response_code(201);
        return $this->signIn($users->findByUsername($username), ['password']);
    }

    // POST /facelogin/login { username?, nonce, liveness, prints }
    public function login() {
        $p = $this->request->parameters();
        $username = $this->username($p);
        if ($username === null) { return $this->fail(422, 'Invalid username'); }
        $key = ($_SERVER['REMOTE_ADDR'] ?? '') . '|' . ($username !== '' ? strtolower($username) : '*');
        [$locked, $failed] = $this->guard($key);
        if ($locked) { return $this->fail(429, 'Too many failed attempts: wait a minute'); }

        try {
            $prints = FaceLogin::verify($p, $username);           // nonce (single use), liveness, prints
        } catch (FaceLoginException $e) {
            return $failed($e->getCode(), $e->getMessage());
        }
        $users = new User('users');
        $target = $username !== '' ? $users->findByUsername($username) : null;
        $match = $username === '' || $target ? FaceLogin::match($prints, $this->enrolled($target ? (int)$target->id : null)) : null;
        if (!$match) {
            return $failed(401, 'Face not recognized');           // same message whether or not the username exists
        }
        $hashes = array_map([FaceLogin::class, 'printHash'], $prints);
        $seen = Database::toArray(Database::execute('SELECT COUNT(*) AS n FROM face_login_used_prints WHERE print_hash IN (' . implode(',', array_fill(0, count($hashes), '?')) . ')', $hashes));
        if ((int)($seen[0]['n'] ?? 0) > 0) {
            return $failed(401, 'These face prints were already used: replay refused');
        }
        foreach ($hashes as $h) {
            Database::execute('INSERT IGNORE INTO face_login_used_prints (user_id, print_hash) VALUES (?, ?)', [$match['user'], $h]);
        }
        Database::execute('DELETE FROM face_login_attempts WHERE attempt_key = ?', [$key]);

        $user = $users->find($match['user']);
        $passkey = new Passkey();
        if (self::PASSKEY_POLICY !== 'face' && $passkey->credentials($user->id)) {
            if (self::PASSKEY_POLICY === 'passkey') { return $this->fail(403, 'This account logs in with its passkey'); }
            $_SESSION[self::PENDING] = ['user' => (string)$user->id, 'expires' => time() + 120];
            return api(['step' => 'passkey', 'options' => $passkey->authenticationOptions($user->id)]);
        }
        return $this->signIn($user, ['face']);
    }

    public function me() {
        if (!authorized()) { return $this->fail(401, 'Not logged in'); }
        return api(['user' => ['username' => user()->username ?? null], 'enrolled' => count($this->enrolled((int)user()->id)) > 0]);
    }
    public function signout() { Auth::unauthorize(); session_regenerate_id(true); return api(['loggedOut' => true]); }
}
```

**`application/controllers/FaceLogin/PasskeyController.php`**:

```php
<?php

use Caligrafy\Controller;
use Caligrafy\Database;
use Caligrafy\Auth;
use Caligrafy\Passkey;
use Caligrafy\PasskeyException;

/**
 * Passkeys (Caligrafy\Passkey): registration for logged-in users, login alone or after face login (step-up)
 */
class PasskeyController extends Controller {

    private function fail($code, $message) { http_response_code($code); return api(['error' => $message]); }

    // the user whose face was just recognized, waiting for the passkey (FaceLoginController::PENDING)
    private function pending() {
        $p = $_SESSION[FaceLoginController::PENDING] ?? null;
        return is_array($p) && $p['expires'] >= time() ? $p['user'] : null;
    }

    // POST /passkey/register/options
    public function registerOptions() {
        if (!authorized()) { return $this->fail(401, 'Log in first'); }
        $user = user();
        return api((new Passkey())->registrationOptions($user->id, $user->username));
    }

    // POST /passkey/register { id, clientDataJSON, attestationObject, transports, name? }
    public function register() {
        if (!authorized()) { return $this->fail(401, 'Log in first'); }
        $p = $this->request->parameters();
        try {
            $credential = (new Passkey())->register($p, user()->id, $p['name'] ?? null);
        } catch (PasskeyException $e) {
            return $this->fail($e->getCode(), $e->getMessage());
        }
        http_response_code(201);
        return api(['passkey' => ['name' => $credential['name']]]);
    }

    // POST /passkey/login/options: after face login only this user's passkeys, else any passkey of the site
    public function loginOptions() {
        return api((new Passkey())->authenticationOptions($this->pending()));
    }

    // POST /passkey/login { id, clientDataJSON, authenticatorData, signature, userHandle }
    public function login() {
        $pending = $this->pending();
        unset($_SESSION[FaceLoginController::PENDING]);
        try {
            $userId = (new Passkey())->authenticate($this->request->parameters());
        } catch (PasskeyException $e) {
            return $this->fail($e->getCode(), $e->getMessage());
        }
        if ($pending !== null && $pending !== $userId) { return $this->fail(401, 'This passkey belongs to another account'); }
        $user = (new User('users'))->find($userId);
        if (!$user) { return $this->fail(401, 'Unknown account'); }
        session_regenerate_id(true);
        Auth::authorize($user);
        return api(['user' => ['username' => $user->username], 'factors' => $pending !== null ? ['face', 'passkey'] : ['passkey']]);
    }
}
```

**Check** (from the command line, before the camera)
- `POST /facelogin/start` with `{"username": "<a user>"}` answers `{"nonce": "<64 hex>", "challenges": [2 of turn-left, turn-right, smile], "expires_in": 60}`.
- `POST /facelogin/login` with a made-up nonce answers `401`, *Unknown or already used challenge: start again*.
- Four identical prints answer `422`, *Identical face prints: they must come from a live camera*; the prints of an
  accepted sign-in sent again with a new nonce answer `401`, *These face prints were already used: replay refused*.

### `Caligrafy\FaceLogin` (static)

| Member | What it does |
|---|---|
| `challenge($username = null, $count = null, $ttl = null)` | `['nonce' => 64 hex, 'challenges' => [...], 'expires_in' => 60]`, kept in the session (a new one replaces the old) |
| `verify($response, $username)` | uses up the nonce, checks the liveness result and the prints; returns the prints (`[[128 numbers], ...]`) or throws `FaceLoginException` (401 nonce, 422 liveness or prints) |
| `match($prints, $enrolled)` | `$enrolled` = `[['user' => id, 'descriptor' => [...]], ...]`; returns `['user', 'distance']` (mean below 0.5, none at 0.6 or more) or `null` |
| `checkPrints($prints)`, `enrolledElsewhere($prints, $enrolled, $user)`, `printHash($descriptor)`, `descriptor($d)`, `distance($a, $b)`, `consume($nonce, $username)` | helpers |
| `CHALLENGES` | `['turn-left', 'turn-right', 'smile']` |
| `$count` 2, `$ttl` 60, `$minPrints` 3, `$maxPrints` 12, `$distinct` 0.001, `$spread` 0.6, `$match` 0.5 | the settings |

### Passkeys

A passkey (WebAuthn) is a key pair kept by the person's device (Touch ID, Windows Hello, Android, a security key or a
password manager) and unlocked with its biometrics or PIN. The private key never leaves the device and a passkey works
only on the domain it was made for: it cannot be phished or replayed. `Caligrafy\Passkey` (on
[lbuchs/webauthn](https://github.com/lbuchs/WebAuthn)) checks them on the server, `PasskeyClient`
(`public/js/services/passkey.js`) runs them in the browser.

**Passkeys alone** (without face sign-in): create the `passkeys` table (the last statement of the SQL above) and add
`'passkeys' => true` to [`Route::auth`](https://github.com/caligrafy/caligrafy-quill/wiki/Declarative-Routes#auth):

```php
Route::auth(['home' => '/', 'passkeys' => true]);
```

It declares `POST /passkey/register/options`, `/passkey/register` (signed in), `/passkey/login/options` and
`/passkey/login`, without a controller. With face sign-in, the `PasskeyController` above takes these routes instead,
because it knows whose face was just recognized.

```js
// <script src="<?php echo APP_SERVICE_ROOT.'passkey.js'; ?>"></script>
const config = { headers: apiHeaders() };   // the session and its X-CSRF-Token
const options = (await axios.post(env.home + 'passkey/register/options', {}, config)).data;
await axios.post(env.home + 'passkey/register', await PasskeyClient.create(options), config);

const login = (await axios.post(env.home + 'passkey/login/options', {}, config)).data;
await axios.post(env.home + 'passkey/login', await PasskeyClient.get(login), config);
```

+ `new Passkey($rpName = APP_NAME, $rpId = PASSKEY_RP_ID or the request host, $origin = PASSKEY_ORIGIN or APP_PROTOCOL://host, $table = 'passkeys')`;
  `registrationOptions($userId, $userName, $displayName = null)`, `register($response, $userId, $name = null)`,
  `authenticationOptions($userId = null)` (null: any passkey of the site), `authenticate($response)` (the user id),
  `remove($userId, $credentialId)`. To store them elsewhere, extend `Passkey` and override `credentials()`,
  `findCredential()`, `saveCredential()` and `touchCredential()`.
+ The challenge of each ceremony is kept in the session, used once, and expires after `$timeout` (120 s).
  `userVerification` and `residentKey` are `required`.
+ In production set `PASSKEY_RP_ID` (the domain, `example.com`) and `PASSKEY_ORIGIN` (`https://www.example.com`) in
  `.env` (they are not in `.env.example`). Passkeys need `https`, except on `localhost`.

| Setup | How | For |
|---|---|---|
| Face only | face sign-in with liveness (`PASSKEY_POLICY = 'face'`) | low-risk apps, as a convenience |
| Face, then passkey | `'step-up'` (the default): accounts with a passkey confirm with it | most apps |
| Passkey only | `'passkey'`: face sign-in refused for accounts with a passkey | administrators, payments, health data |
| Passkey as fallback | the sign-in page always offers a passkey | every setup: the camera can be missing or blocked |

Enrol faces and passkeys only for people who are signed in (with their password), so that nobody can attach a face or
a passkey to someone else's account.

### Testing without a camera or a device

+ **A fake camera:** draw a picture on a canvas and give its stream to the page before the detector starts:
  `navigator.mediaDevices.getUserMedia = async () => canvas.captureStream(15);`. `faceprint()` works on it and
  `liveness()` must fail: this is the photo test.
+ **Virtual passkeys:** Chrome DevTools > More tools > WebAuthn > *Enable virtual authenticator environment*, then add
  an authenticator (internal, resident keys, user verification).

## Common mistakes

+ **A detector in Vue `data` without `Vue.markRaw()`.** The detections slow down or stop.
+ **Recognition pictures that differ in number**, or `sampleSize` missing: `sampleSize` 0 loads nothing.
+ **The camera on `http://` with another host than `localhost`.** Browsers allow the camera only on `https` or `localhost`.
+ **A face print as a password.** Use the server challenge, `liveness()`, `FaceLogin::verify()`, and a passkey.
+ **`blink` in the challenges.** It was removed: `liveness()` refuses it.
+ **Both `Route::auth(['passkeys' => true])` and the passkey routes of the face login.** Keep one.
+ **An app folder with a reserved name**: `app`, `bot`, `__bots__`, `css`, `facedetect`, `fonts`, `images`, `js`, `ml`,
  `resources`, `uploads`.
