# 9.7.6 Components

> Source: Caligrafy Quill wiki - https://github.com/caligrafy/caligrafy-quill/wiki/9.7.6-Components
> Bundled with the caligrafy-quill Claude plugin. Content preserved from the wiki; formatting cleaned.

A **component** is a piece of a Vue screen with its own markup and behaviour, used like a new HTML tag: `<book-row>`, `<book-form>`. A parent passes data down to it through **props** and hears from it through **events**. In a Vue app as a library, components are registered in `scripts/main.js` with `app.component()`, and their markup lives in the `.php` file inside `<script type="text/x-template">` blocks. For larger apps, each component gets its own `.vue` file in a [single page app](https://github.com/caligrafy/caligrafy-quill/wiki/9.8.3-Single-File-Components).

## With Claude

Ask for the split: "in the bookshelf app, make the book row and the add form two components; the page keeps the data and calls the capabilities". Claude registers them in `public/bookshelf/scripts/main.js` and puts their templates in `public/bookshelf/index.php`.

**Check** before you say OK:
+ Each component is registered with `app.component()` **before** `app.mount('#app')`.
+ Each template is a `<script type="text/x-template" id="...">` outside `<div id="app">`, with one root element.
+ Data flows down through props, and up through events declared in `emits`: a component never changes its props.
+ Only the page (the root app) calls the capabilities.

## By hand

You split the Bookshelf app of [Setting up Vue as a library](https://github.com/caligrafy/caligrafy-quill/wiki/9.7.0-Setting-up-Vue.js-as-a-library) into two components: `book-row` shows one book, `book-form` keeps what is typed, gets the authors and the errors from the page, and sends an `add` event.

**1. The markup.** Replace `public/bookshelf/index.php` with:
```php
<!DOCTYPE html>
<html lang="en">
    <head>

        <meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
        <title>Bookshelf</title>
        <link rel="shortcut icon" href="<?php echo scripts('favicon'); ?>" type="image/x-icon" />

        <link rel="stylesheet" href="<?php echo session('public').'css/theme.css';?>">
        <link rel="stylesheet" href="<?php echo session('public').'css/tokens.css';?>">
        <link rel="stylesheet" href="<?php echo session('public').'css/layout.css';?>">
        <link rel="stylesheet" href="<?php echo session('public').'css/look.css';?>">
        <?php if (design_stylesheet()): ?><link rel="stylesheet" href="<?php echo design_stylesheet(); ?>"><?php endif; ?>
    </head>

    <body class="cq-site">
        <div id="app" v-cloak>
            <nav class="cq-nav" aria-label="Main">
                <a class="cq-nav-brand" :href="env.home"><img class="cq-nav-mark" :src="env.home + 'public/images/resources/caligrafy-mark.svg'" alt="" width="28" height="28"><span class="semibold">Book</span>shelf</a>
            </nav>
            <section class="cq-hero cq-hero--page">
                <h1 class="cq-display">Books</h1>
                <p class="cq-lead">{{ total }} books on the shelf.</p>
            </section>
            <section class="cq-band cq-band--tight">
                <div class="cq-inner cq-inner--narrow">
                    <p class="cq-alert cq-alert--error" role="alert" v-if="error">{{ error }}</p>
                    <book-form :authors="authors" :errors="errors" @add="addBook"></book-form>
                    <ul class="cq-rows" v-if="books.length">
                        <book-row v-for="item in books" :key="item.id" :book="item"></book-row>
                    </ul>
                    <p class="cq-empty-state" v-else>No books yet: add the first one above.</p>

                        <button class="btn btn-secondary" type="button" :disabled="page === 1" @click="load(page - 1)">Previous</button>

        <script type="text/x-template" id="book-row">
            <li class="cq-row">
                <div class="cq-row-main">
                    <p class="cq-row-title">{{ book.title }}</p>
                    <p class="cq-row-meta">{{ book.author.name }}, {{ book.published_year }}</p>

                <div class="cq-form-grid cq-form-grid--2">
                    <div class="cq-field">

                    <div class="cq-field">
```

**2. The script.** Replace `public/bookshelf/scripts/main.js` with:
```js
// Bookshelf: the books of the catalog, through the generated JS client (public/js/capabilities.js)
const app = Vue.createApp({
    data () {
        return {
            env: env,
            books: [], total: 0, page: 1, pages: 1,
            authors: [],
            errors: {},
            error: ''
        }
    },
    async mounted () {
        this.api = await import(env.home + 'public/js/capabilities.js')
        this.api.configure({ baseUrl: env.home.replace(/\/$/, '') })   // the application root, whatever APP_ROOT is
        this.authors = await this.api.listAuthors()
        await this.load(1)
    },
    methods: {
        async load (page) {
            const result = await this.api.listBooks({ page: page })   // { data, total, page, per_page, pages }
            this.books = result.data
            this.total = result.total
            this.page = result.page
            this.pages = result.pages
        },
        async addBook (book, done) {
            this.errors = {}
            this.error = ''
            try {
                await this.api.createBook(book)
                done()
                await this.load(1)
            } catch (e) {
                if (e.name === 'CapabilityError' && e.code === 'invalid') this.errors = e.fields
                else this.error = e.message
            }
        }
    }
})

// One book of the list: the parent passes it as a prop
app.component('book-row', {
    template: '#book-row',
    props: ['book']
})

// The form: it keeps what is typed, shows the errors the parent passes, and sends 'add' with the book
app.component('book-form', {
    template: '#book-form',
    props: ['authors', 'errors'],
    emits: ['add'],
    data () {
        return { book: { title: '', author_id: null, published_year: null, summary: '' } }
    },
    methods: {
        submit () {
            this.$emit('add', { ...this.book }, () => { this.book = { title: '', author_id: null, published_year: null, summary: '' } })
        }
    }
})

app.mount('#app')
```
The form sends a copy of the book and a `done` function; the page calls the capability and calls `done()` only when the book was added, so a refused book stays in the fields.

**3. Try it.** Reload `http://localhost:8080/bookshelf`:
+ The list shows the books, each drawn by `book-row`.
+ `Lilith` with Octavia E. Butler and no year: `The Published Year field is required` under the year (the page passed `errors` down), and the title stays.
+ With the year `1989`: the count goes up, *Lilith* is in the list and the fields empty.

**Check**
+ In the browser's element inspector, each row is a `li.cq-row` directly inside `ul.cq-rows`, and no `<book-row>` tag is left in the page (an unknown component stays as its tag).
+ The browser console shows no error other than the `422` of a refused book. (`scripts('vue')` is Vue's production build, which prints no development warnings.)

## Reference

| Property | What it is |
| --- | --- |
| `template` | `'#id'` of a `<script type="text/x-template" id="id">` in the markup, or the markup itself in a string |
| `props` | the values the parent passes: `props: ['book']`, used as `<book-row :book="item">` (`:` binds a value; without it the attribute is a fixed string) |
| `emits` | the events it sends: `emits: ['add']`, sent with `this.$emit('add', ...values)`, heard with `@add="addBook"` (the method gets the values) |
| `data()`, `methods`, `computed`, `watch`, `mounted()` | as for the app itself |
| slots | markup the parent places between the tags: `<slot></slot>` in the template, `<slot name="actions">` for a named one, filled with `<template v-slot:actions>` |

Register every component on the app returned by `Vue.createApp()`, before `app.mount('#app')`. A component name used in HTML markup is written in lowercase with dashes (`book-row`), because the browser reads `#app` as HTML before Vue does. A component's template has one root element.

Vue's guides: [components](https://vuejs.org/guide/essentials/component-basics.html), [props](https://vuejs.org/guide/components/props.html), [events](https://vuejs.org/guide/components/events.html), [slots](https://vuejs.org/guide/components/slots.html).

## Other ways

+ **The template in the script**: `template: '<li class="cq-row">...</li>'`. It works, and mixes markup into the script: keep templates in the markup file.
+ **`v-model` on a component** (`<book-title v-model="book.title">`): the component declares the prop `modelValue` and the event `update:modelValue`; see Vue's [component v-model](https://vuejs.org/guide/components/v-model.html).

## Common mistakes

+ **`app.component()` after `app.mount()`**: the tag stays unknown.
+ **A template inside `<div id="app">`**: Vue renders it as part of the page. Keep the `x-template` blocks after it.
+ **A component that changes its prop** (`this.errors = {}` in `book-form`): Vue warns and the parent's value does not change. Send an event; the parent changes its data.
+ **A component that calls the capabilities itself**: every row would call the server. Keep the calls in the page and pass the results down.
