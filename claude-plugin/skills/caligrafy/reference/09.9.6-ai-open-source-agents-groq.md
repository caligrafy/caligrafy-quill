> Bundled with the caligrafy-quill Claude plugin. Content preserved from the wiki; formatting cleaned.

> **Verified against framework source (see gotchas.md):**
> - The .env key is `GROQ_API_KEY` (not GROQ_AI_KEY). `delegate()` is positional: `delegate($model, $messages, $response_format = [], $stream = false, $tool_choice = '', $tools = [])`. Default vision model may be retired on Groq - pass a current one.

Artificial Intelligence has made significant strides in the last couple of years especially - unexpectedly - in the creative world. Many open source providers like Meta have been a major player in bringing generative artificial intelligence to the mass. 

Caligrafy integrates seamlessly with many of the AI models provided by  to give the opportunity for developers to use them easily and to build next generation applications.

## Initializing open source models

### Step 1: Reference open source models (llama, mistral and others)

In order to help developers quickly use the open source models with minimal effort, we will be using them by inference from a service called groq. 

* [Open a grok account for free](https://console.groq.com/playground)
* [Create an API key](https://console.groq.com/keys)
* Once the API key create, paste it in the `.env` file next to the `GROQ_AI_KEY=<paste your key here>`
* Explore all the open source models that are offered on [grok.com](https://console.groq.com/playground). The models keep evolving and more are added with time. 

### Step 2: Create a controller to interface with the models

Create a controller in Caligrafy that uses the Agent class to interface with the models

```php
<?php

use Caligrafy\Controller;
use Caligrafy\Agent; // <---- Make sure to include the Agent class

class AgentController extends Controller {

    public function index() {

         $agent = new Agent(); // The API is taken from .env file. Otherwise specify as argument new Agent('your api key')

         // 4 methods can be called on the agent object
         $delegate = $agent->delegate(...);
         $visualize = $agent->visualize(...);
         $transcription = $agent->transcribe(...);
         $translation = $agent->translate(...);

         // Render output
         dump($delegate); // use dump for flushing result on the browser
         return api($delegate); // use api function to show api result
         return view(...); // use view function to return response to view
    }
}

```

## Using the AI methods

4 methods are provided for you to use with all the open source models.

### Delegate (Prompting engine)

This method is a textual prompting engine that could help query, converse and delegate tasks to the AI

```php

public function delegate (

       model: "model name taken from groq",
       messages: array(
            [
               'role' => 'user', // or system
               'content' => 'your message goes here'
            ]
       ),
       // response_format: ['type' => 'json_object'],
       // stream: false 
       
)

```

### Visualize

Interprets the content of an image file

```php
public function visualize (

       file: "file path goes here",
       prompt: "optional prompt if something specific is needed from the image",
       model: "model name from groq goes here" // default is llama-3.2-11b-vision-preview at the time of this documentation
       
)

```

### Audio Transcribe

Converts audio files to text

```php
public function transcribe (

       file: "file path goes here",
       prompt: "optional prompt if something specific is needed from the image",
       model: "model name from groq goes here" // default is whisper-large-v3 at the time of this documentation
       // 'response_format' => 'json',
       // 'language' => 'en' // helps accelerate transcription if language is known
       
)

```
