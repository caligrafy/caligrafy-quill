# 9.9.3 Machine Learning

> Source: Caligrafy Quill wiki - https://github.com/caligrafy/caligrafy-quill/wiki/9.9.3-Machine-Learning
> Bundled with the caligrafy-quill Claude plugin. Content preserved from the wiki; formatting cleaned.

**ML Core** brings machine learning to the browser: it detects body poses in a camera, learns from pictures, and
trains small neural networks of your own. It is a JavaScript class, `MlCore` (`public/js/services/mlcore.js`), built
on [ml5.js](https://docs.ml5js.org) 1.4 (itself on TensorFlow.js), with [p5.js](https://p5js.org/reference/) 2.x for
drawing and controls. Everything runs in the browser: nothing is sent to your server unless your code sends it.

In the Bookshelf example, a page learns how many hours a book takes to read from its number of pages.

> #### (video) [Creating and training an AI with Caligrafy](https://youtu.be/hBSWkaaBbNM)
>
> The video builds neural networks and computer vision with Caligrafy to detect people and objects and to predict outcomes.

## By hand

Run the commands in the project folder of the [Quickstart](https://github.com/caligrafy/caligrafy-quill/wiki/Quickstart).

```bash
docker compose exec dev-box php caligrafer.php ml reading
```

### Step 3: Your own neural network

Create **`public/reading/readingtime.php`** (opened with `?app=readingtime`):

```html

<html lang="en">

        <link rel="stylesheet" href="<?php echo session('public').'css/layout.css';?>">
        <link rel="stylesheet" href="<?php echo session('public').'css/look.css';?>">

            <div class="cq-inner cq-inner--narrow">

                <form id="guess" method="POST">

                        <label for="pages">Pages</label>
                        <input id="pages" class="form-control" type="number" name="pages" min="1" value="350" required>

        <script src="<?php echo APP_SERVICE_ROOT.'app.js?v='.@filemtime(PUBLIC_PATH.'js/services/app.js'); ?>"></script>
        <script>loadEnvironment(`<?php echo $env; ?>`);</script>

        <script>loadVue({ scripts: ['readingtime'] });</script>
    </body>

```

`loadVue({ scripts: [...] })` adds `public/reading/scripts/<name>.js` to the page. Create
**`public/reading/scripts/readingtime.js`**:

```js
// A neural network that learns the hours a book takes to read from its number of pages (regression)
const myMl = new MlCore({
    media: 'none',    // no camera: the page has no <video id="video">
    canvas: 'none',
    brain: { type: 'neuralnetwork', options: { inputs: ['pages'], outputs: ['hours'], task: 'regression' } }
});

const status = document.getElementById('status');
const form = document.getElementById('guess');
const answer = document.getElementById('answer');

myMl.ready.then(() => {
    // the examples: pages read -> hours it took
    [[120, 3], [200, 5], [300, 7.5], [400, 10], [500, 12.5], [640, 16]]
        .forEach(([pages, hours]) => myMl.brain.addData({ pages: pages }, { hours: hours }));
    myMl.brain.normalizeData();
    myMl.brain.train({ epochs: 60 }, () => {
        status.textContent = 'Trained on 6 books.';
        form.querySelector('button').disabled = false;
    });
});

form.addEventListener('submit', (event) => {
    event.preventDefault();
    const pages = Number(form.elements.pages.value);
    myMl.brain.predict({ pages: pages }, (results, error) => {
        answer.textContent = error ? 'No guess: ' + error : 'About ' + results[0].value.toFixed(1) + ' hours';
    });
});
```

Open `http://localhost:8080/ml/reading?app=readingtime`. *Training...* becomes *Trained on 6 books.* after a few
seconds and **Guess** turns on. Click it: *About 8.7 hours* (the number varies a little from one training to the next).
Training pauses while the browser tab is hidden.

To keep what a network learned, `myMl.brain.save('reading')` downloads its files (the model `.json`, its
`_meta.json` and its `.weights.bin`); put them in `public/reading/resources/` and load them with
`myMl.brain.load(<the address of the model .json>, callback)` instead of training. To keep data on
the server (the readers' own reading times, for example), send it to a capability with the
[JS client](https://github.com/caligrafy/caligrafy-quill/wiki/11.-Build-Once:-Services,-Capabilities-and-MCP#client).

**Check**
- The four example addresses open (with the camera allowed, the pose page draws on you).
- `?app=readingtime` shows *Trained on 6 books.* and a guess.
- The browser console has no errors.

## Reference

### `new MlCore(settings)`

| Setting | Default | What it is |
|---|---|---|
| `media` | `'video'` | the id of the `<video>` or `<img>`; a `<video>` without `src` starts the camera |
| `canvas` | `'canvas'` | the id of the drawing canvas |
| `brain` | `{ type: 'neuralnetwork', options: { inputs: 34, outputs: 2, debug: true, task: 'classification' } }` | the brain (below) |
| `filter` | `false` | `true`: keeps only the person and removes the background (ml5 `bodySegmentation`) |
| `hideVideo` | `false` | hides the video under the drawing |
| `backend` | `'webgl'` | the TensorFlow.js backend of the neural networks |

| `brain.type` | What it is | `brain.options` |
|---|---|---|
| `neuralnetwork` | an ml5 neural network | `inputs`, `outputs` (numbers or names), `task` (`classification` or `regression`), `debug`... |
| `featureextractor` | MobileNet, retrained on your labeled pictures | `epochs`, `batchSize` (for training); `version`, `alpha`, `task` (for MobileNet) |

`myMl.ready` is a promise that resolves when the brain and the camera are ready; `myMl.brain` is the ml5 object.

### Body poses

```js
var myMl = new MlCore();
myMl.detect((myMl) => {
    myMl.drawKeypoints(myMl);   // the 17 points
    myMl.drawSkeleton(myMl);    // the lines between them
    // myMl.poses: the poses of this frame
});
myMl.stopDetection();
```

`detect(callback, ...args)` runs ml5 `bodyPose` (MoveNet) on the media and calls `callback(myMl, ...args)` at every
frame. Each pose of `myMl.poses` has both shapes, scaled to the canvas:

```js
let pose = myMl.poses[0];
pose.keypoints        // 17 keypoints {x, y, confidence, name}: nose, left_eye, right_eye, left_ear, right_ear,
                      // left_shoulder, right_shoulder, left_elbow, right_elbow, left_wrist, right_wrist,
                      // left_hip, right_hip, left_knee, right_knee, left_ankle, right_ankle
pose.nose             // {x, y, confidence}, the same for every name
pose.box              // the box around the person
pose.pose.keypoints   // the earlier shape: [{part: 'leftEye', position: {x, y}, score}, ...]
pose.pose.leftEye     // camelCase names
pose.skeleton         // [[keypointA, keypointB], ...] for the visible connections
```

### Methods

| Method | What it does |
|---|---|
| `drawKeypoints(myMl)`, `drawSkeleton(myMl)` | draw the pose |
| `drawFeature(myMl, ['nose', 'left_eye'])` | draw some keypoints (snake_case or camelCase names) |
| `addData(myMl, label)` | body poses: adds the 34 coordinates of the current pose with a label |
| `addImage(myMl, label)` | feature extractor: adds the current frame with a label |
| `train(myMl, options = {})` | trains (`{ epochs, batchSize }`), then classifies continuously |
| `classify(myMl)` | classifies the current pose or frame; the best label is in `myMl.brain.results`, e.g. `Happy (93)%` |
| `save(name, callback, myMl)`, `load(fileOrPath, callback, myMl)` | download the model, load a saved one |
| `toP5(myMl)` | hands the canvas to p5 (call it in `setup()`): `draw()` then runs at every frame |
| `startStream()` | starts the camera (called by the constructor for a `<video>` without a source) |

On a neural network you can call ml5 directly: `myMl.brain.addData(inputs, outputs)`, `normalizeData()`,
`train(options, callback)`, `classify(input, (results, error) => ...)` (classification: `results[0].label`,
`results[0].confidence`), `predict(input, (results, error) => ...)` (regression: `results[0].value`), `save()`, `load()`.

### Drawing with p5

```js
function setup() {
    myMl.toP5(myMl);            // p5 now draws on the canvas
}

function draw() {               // runs only after toP5()
    if (myMl.poses.length > 0) {
        let nose = myMl.poses[0].nose;
        fill(255, 0, 0);
        ellipse(nose.x, nose.y, 50);
    }
}
```

p5 2.x has no `preload()`: use `async function setup()` to wait for something. Its DOM functions (`createButton`,
`createElement`) are part of p5 itself.

## Common mistakes

+ **ml5 0.x code.** ML Core 2.0 follows ml5 1.x: `poseNet` became `bodyPose`, callbacks are `(results, error)`, models
  load asynchronously (wait for `myMl.ready`).
+ **`preload()` with p5 2.x.** It no longer exists.
+ **A page without a camera that keeps `<video id="video">`.** It asks for the camera: remove it and give `media: 'none'`.
+ **Training in a hidden tab.** The browser pauses it until the tab is visible again.
+ **An app folder with a reserved name**: `app`, `bot`, `__bots__`, `css`, `facedetect`, `fonts`, `images`, `js`, `ml`,
  `resources`, `uploads`.
