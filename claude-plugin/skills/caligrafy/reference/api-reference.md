# Caligrafy Quill API reference (verified against the framework source)

> Every signature below was copied from `framework/core/*.php`, `framework/helpers/corehelpers.php` and
> `framework/database/Database.php` of caligrafy-quill (master). When the wiki and the source disagree, the
> source wins and the difference is listed in [gotchas.md](gotchas.md).
> Everything lives in the `Caligrafy` namespace except the global helper functions and your own
> application classes (which are in the global namespace).

## Bootstrap and request lifecycle
- 2.19.8: `framework/helpers/initialize.php` sets `session.cookie_httponly=1` and, on HTTPS (`$_SERVER['HTTPS']` or `X-Forwarded-Proto: https`), `session.cookie_secure=1`, before any session starts.

1. `index.php` sets `error_reporting(E_ALL & ~E_DEPRECATED & ~E_USER_DEPRECATED)`, loads `vendor/autoload.php`, then `Dotenv\Dotenv::createUnsafeMutable(__DIR__)->load()` (the `.env` file **overrides** variables already in the environment, e.g. docker-compose `environment:`).
2. `Framework::run()`:
   - `framework/helpers/initialize.php`: sets timezone (`SERVER_TIMEZONE`), `session_start()`, creates `$_SESSION['token']` (CSRF token), defines path constants and the session URLs (`base`, `home`, `public`, `uploadsUrl`, `jsUrl`, `cssUrl`, `imagesUrl`, `appClient`, `appService`, `appResources`) plus constants `APP_CLIENT`, `APP_SERVICE_ROOT`, `APP_RESOURCES`.
   - loads `corehelpers.php`, then `loadConstantFromArray($_ENV)`: **every `.env` key becomes a PHP constant** (string values).
   - `framework/settings/coresettings.php`: `ROUTE_ARG_PATTERN` (`#\{+(.*?)\}+#`), default `scripts()`, `metadata()`, `keywords()`, `copyright()`.
   - registers the class map (2.18.0, [ClassMap](#classmap)): a map of the classes of `framework/core`, `framework/database`, `framework/interfaces` and `application/` (minus `config/` and `views/`; `FRAMEWORK_MOVED_FILES` skipped) loads each class when it is first used, and the files that declare functions or run top-level code at start. `tests/` is never loaded. With `CLASS_MAP=false`: the old autoloader, which `require_once`s every `.php` file of those folders (max depth 5) on the first unknown class.
   - `include application/config/config.php`, then `require_once application/config/routing/web.php`.
3. `web.php` declares routes then calls `Route::run()`, wrapped in `try { ... } catch (Exception $e) { Errors::handle($e); }` (older projects: `echo $e->getMessage();`, see Errors below).

Path constants: `ROOT` (cwd), `APP_PATH` (application/), `TEST_PATH`, `FRAMEWORK_PATH`, `PUBLIC_PATH`, `CONFIG_PATH`, `ROUTING_PATH`, `CONTROLLER_PATH`, `MODEL_PATH`, `VIEW_PATH` (application/views/), `CORE_PATH`, `DB_PATH`, `LIB_PATH` (framework/librairies/), `HELPER_PATH`, `UPLOAD_PATH` (public/uploads/), `FONTS_PATH`, `DS`.

URL building: `session('home')` = `APP_PROTOCOL://SERVER_NAME[:port]/` + `APP_ROOT/` (when `APP_ROOT` is non-empty). `session('public')` = home + `public/`.

## Route (`Caligrafy\Route`)
- 2.16.0: `evaluate()` with no matching route raises 1005 (404), or 1000 (405, `Allow` header) when `pathMatches()` finds the address under other methods; `/` is matched by a route with no components and the same method; `HEAD` is matched as `GET`.

```php
Route::get(string $route, string|callable $method = null)
Route::post(string $route, string|callable $method = null)
Route::put(string $route, string|callable $method = null)
Route::delete(string $route, string|callable $method = null)
Route::page(string $route, string $view, array $options = [])   // 2.5.0+: a GET route rendered by Caligrafy\PageController::render($view, $options)
Route::form / Route::auth / Route::webhook / Route::download / Route::redirect   // 2.19.0: see Declarative routes
Route::action(string $route, string $capability, array $options = [])   // 2.21.0: a webOnly capability answers: see Declarative routes
Route::bots()                      // 2.21.0: the data routes of the Watson bot apps
Route::run()                       // MUST be the last call in web.php
Route::$currentRoute               // matched route pattern, e.g. "books/{id}"
Route::$currentBind                // ['id' => '12', ...] (+ query string params for GET routes)
```
- `$method` is `'Controller'` (runs `index`), `'Controller@action'`, or a closure. The controller may be fully qualified (`'Shop\OrderController@show'`, leading `\` allowed). `Route::resolveController($name)`: a declared class wins; else a short name falls back to `Route::EXAMPLE_CONTROLLERS_NAMESPACE` (`Caligrafy\Controllers`, the example controllers of `controllers/core/`); else `null` -> 1001 (G47).
- Leading/trailing slashes are stripped; a route matches only if it has the **same number of segments** and the **same HTTP method** as the request; `{name}` segments capture values.
- No match answers 404 (1005), or 405 (1000, with `Allow`) when the address exists under other methods (2.16.0, above; before 2.16.0 it fell back to the first route declared, G4). Route order only matters between routes that match the same address.
- For controller routes: missing class/method throws `[ERROR 1001]` (404); a JSON request (`wantsJson()`) is accepted with the session's CSRF token in `X-CSRF-Token` (a page of the app, 2.7.0+) or, with `Auth::activateAPI()`, a valid Bearer (token granting `*`, or the legacy key); else `[ERROR 1004] Access Denied: <why>` (401, `Request::apiRefusal()`). Closure routes skip the API-key check.
- Method spoofing: a `_method` field (`PUT`/`DELETE`) in `$_REQUEST` overrides the HTTP method.
- `Route::page()` (2.5.0, `framework/core/{Route,PageController}.php`): registers `Route::get($route, closure)` that runs `(new PageController())->render($view, $options)`. `PageController::__construct()` does nothing (no database connection); `render()` calls `parent::__construct()` only when the page has `data`. Steps: `level` (int) or `signedIn` (bool) without `Auth::active()` throws `LogicException`; with it, `Auth::guard(Context::$levelAttribute, $level)` (visitors -> `/login`, lower level -> `/notAuthorized`). View data starts from `PageController::routeVariables()` (`bindRouteToVar(Route::$currentRoute, $request->uri)`: the route pattern's variables only, never the query string), then `with`, then each `data` entry `name => 'capability'` or `name => ['capability', $inputs]`: `LogicException` when the capability does not exist or is not `readOnly`, or when the name is `authorized` or `user` (`PageController::RESERVED`, also for `with` and `query`); called with `$this->call($capability, $inputs ?? array_merge($request->parameters, routeVariables()))` (the route variables win over the query string). A `ServiceError`: `unauthenticated` with auth active -> `redirect('/login')`; `forbidden`, or `unauthenticated` without auth -> `Errors::raise(1006)` (403); anything else (`not_found`, `invalid`, `conflict`) -> the `notFound` view with `http_response_code(404)` and `routeVariables() + with + ['message' => ...] + identity()` when the option is set, else `Errors::raise(1005)` (404). The view gets `array_merge($data, PageController::identity())`: `identity()` = `['authorized' => Auth::active() && Auth::authorized(), 'user' => ['id', 'username', 'permissions' (the Context::$levelAttribute column)] or null]`.

## Auth (`Caligrafy\Auth`)

```php
Auth::activateAPI()                                   // allow Bearer access (tokens, legacy key) to controller routes; pages need none (X-CSRF-Token)
Auth::authentication(string $modelname, string $tablename)   // e.g. Auth::authentication('User', 'users')
Auth::authorize($user): bool                          // $user must be an instance of the auth model; stores encrypted user in session '__authorization'
Auth::unauthorize()
Auth::authorized(): bool                              // re-reads the user by id from the DB and compares with the session copy
Auth::guard($permissionAttribute, $acceptedPermission, $loginUrl = "/login", $notAuthorized = '/notAuthorized')
Auth::logout($redirectUrl = '/')                      // unauthorize + session_destroy + redirect + exit
Auth::user(): ?Model                                  // user model rebuilt from the session (not re-read from DB)
Auth::api(): bool
```
- `guard()` redirects (and exits) to `$loginUrl` when not logged in, to `$notAuthorized` when `$user->$permissionAttribute < $acceptedPermission`.
- `Auth::authentication()` must run in `web.php` before any `authorize/authorized/user/guard` call.
- API key check (`Request::authorizeApiRequest`): header `Authorization: Bearer <API_KEY>`; valid when `encryptDecrypt('decrypt', <API_KEY>) == APP_KEY`. So any key produced by `caligrafer generateapikey` for the current `APP_KEY` works.

## Request (`Caligrafy\Request`)

Created fresh by `request()` and in every controller (`$this->request`).

Public properties:
```php
$method          // HTTP method, after _method spoofing (upper case)
$uri             // path without leading/trailing slash ('/' for root); from ?uri= set by .htaccess
$fullUri         // uri + '?' + query string of the parameters
$uriComponents   // explode('/', $uri)
$uriParameters   // request body/query parameters (see parameters())
$parameters      // = $uriParameters, or the route bind when there are none
$fetch           // (object) route bind: route {vars} + (GET routes) query string params -> $this->request->fetch->id
$currentRoute, $currentBind
$host, $authorization, $cache, $userAgent, $accept, $acceptEncoding, $acceptLanguage, $cookie, $parsedURI
```
Methods:
```php
fetch($argument)            // by name: $this->request->fetch->$argument ?? ''; by int: nth bound value (1-based)
parameters(): array         // GET: $_GET; POST/PUT/DELETE: $_POST if non-empty else json_decode(php://input) (also runs the CSRF check)
files($fileAttribute): array  // $_FILES[$fileAttribute] ?? []
wantsJson(): bool           // true when Accept contains application/json AND not text/html
authorizeApiRequest(): bool
forClient(): array          // 2.19.1: what a client app page may see (env.request of Client/app.pug), see below
```
- `forClient()` (2.19.1) = `method`, `host`, `uri`, `fullUri`, `uriComponents`, `uriParameters` (GET: the query string; other methods: `$_GET` only, never the POST body; `_token` removed), `parameters` (those, or the route bind when empty), `parsedURI`, `currentRoute`, `fetch` (the route bind as an object), `acceptLanguage`. Never `cookie` (the session id), `authorization` (a bearer token) or any other header. `views/Client/app.pug` passes `'request' => request()->forClient()` to `env.request` since 2.19.1; before, it passed the whole `request()`, so every client page printed the session cookie and the `Authorization` header into its JavaScript. Older projects get the new view with `php caligrafer.php upgrade --apply` (or `update`), G136.
CSRF (`checkCSRF`, run for POST/PUT/DELETE whenever a Request is built): skipped when `wantsJson()` is true, the User-Agent is listed in `APPROVED_AGENTS` (comma separated; entries are trimmed and empty entries ignored), a bearer is present (G54), the POST goes to a declared webhook (`Route::isWebhook`) or, since 2.19.1, to a `Route::mcp` address (`Route::isMcp($uri)`: `Mcp\Http` answers 401 + `WWW-Authenticate: Bearer error="invalid_token"` without a personal access token and never acts as the session's user, so a cross-site post with the cookie does nothing there; before, an MCP client posting without `Accept: application/json` got the 3000 page instead of the 401). Otherwise `$_POST['_token']` must equal `$_SESSION['token']`, else `[ERROR 3000] Security Error - Cross Site Forgery`. The token is read from `$_POST` only (form-encoded or multipart), never from a JSON body.

## Controller (`Caligrafy\Controller`)

```php
class BookController extends Controller { public function index() { ... } }   // global or namespaced (namespace Shop; -> 'Shop\BookController@index'), use Caligrafy\Controller;

protected $loader;      // Caligrafy\Loader: ->library($lib) includes LIB_PATH/$lib.php, ->helper($h) includes HELPER_PATH/$h.php
protected $request;     // Caligrafy\Request
protected $model;       // Caligrafy\Model (set by associate)
protected $connection;  // PDO or null (connect())
protected $validator;   // Caligrafy\Validator (extends GUMP)
protected $payment;     // Caligrafy\Payment after activatePayment(), else null

associate($modelname, $table): Controller   // $modelname: class name string or Model instance; swaps $this->model (keeps request/validator, reconnects DB)
activatePayment(): Controller              // $this->payment = new Payment()
index()                                    // default action
all($args = array())                        // -> $this->model->all($args)
find($id = null)                            // id defaults to $this->request->fetch('id') (route {id})
save($inputs, $id = null)                   // id defaults to route {id}: with an id -> model->update($inputs, $id), else model->create($inputs); returns the saved Model (re-read)
delete($id = null)                          // id defaults to route {id}
search($scope = null, $keywords = null)     // defaults from request fetch->scope / fetch->keywords -> model->search()
table(): string
check($data, $rules = array(), $filters = array())   // see Validator::check
validate($data, $rules)                     // true, or ['field' => 'message', ...]
filter($data, $filters)                     // filtered array
view($viewName, $viewData = array())        // -> view()
api($viewData = array())                    // -> api()
```
Do not override these method names in your controllers.

## Model (`Caligrafy\Model`)

```php
use Caligrafy\Model;
class Book extends Model {
    public $id; public $title; public $author; public $publisher_id; public $created_at;   // one public property per column
}

public $table;
protected $__restricted;            // ['table', '__restricted', 'pivot'] + relationship method names; never written to the DB

__construct($table = null)
associate($table): Model
create($inputs): ?Model             // array or object; skips null values and restricted keys only (0, '', false -> 0 are saved); column names validated; INSERT with bound values; returns find(lastInsertId)
update($inputs, $id): ?Model        // same preparation; UPDATE ... WHERE id = ? (bound), skipped when the record does not exist or nothing is left to save; returns find($id)
delete($id)                         // DELETE ... WHERE id = ? (bound)
find($id): ?Model                   // SELECT * ... WHERE id = ? (bound); not declared since the query builder: __call() runs it on an instance, __callStatic() makes Book::find($id) the builder's (see Queries)
all($args = array()): Model[]       // 'SELECT * FROM table' . ' '.$args['condition'].' ' . ' '.$args['order'].' ' . ' '.$args['limit'].' '  (raw clauses) executed with $args['bindings'] (array) for ? placeholders
search($scope, $keywords): Model[]  // $scope = 'col1,col2' (each must match [A-Za-z0-9_], else Exception 2001); WHERE `col1` LIKE ? OR `col2` LIKE ?  (keywords bound; % and _ are wildcards)
save()                              // $this->id ? update($this, $this->id) : create($this)
hasOne($modelName, $joinedTableName, $foreignKey = null, $localKey = null, $functionName = null): ?Model
hasMany($modelName, $joinedTableName, $foreignKey = null, $localKey = null, $functionName = null): Model[]   // ids bound
belongsTo($modelName, $joinedTableName, $foreignKey = null, $localKey = null): Model[]   // calls hasMany()
belongsToMany($modelName, $joinedTableName, $foreignKeyLocal = null, $foreignKeyJoin = null, $functionName = null): Model[]
attach($joinedTableName, $id)       // many-to-many: add pivot row (call the relationship method first), returns the relationship method's result
detach($joinedTableName, $id)
arrayToModel($array): Model         // new static($this->table) hydrated with the array
toArray(): array
tableExists($tablename): bool
// protected helpers: prepareInputs($inputs) (non-null values of real columns), tableColumns(), quoteIdentifier($name), columnType($table, $column), constraintName($pivot, $column)
```
Relationship key defaults (from source):
- `hasOne('Account','accounts')` on `User` (table `users`): `SELECT accounts.* FROM users LEFT JOIN accounts ON accounts.id = users.account_id WHERE users.id = <this id>` (FK `<lowercase model>_id` lives on **this** table; `$foreignKey` overrides that column, `$localKey` overrides `accounts.id`).
- `hasMany('Account','accounts')` on `User`: `SELECT * FROM accounts WHERE user_id = <this id>` (FK `<lowercase this class>_id` on the **joined** table; `$foreignKey` overrides it; `$localKey` names a property of this model to use instead of `id`).
- `belongsToMany('Account','accounts')` on `User`: pivot table `users_accounts` (or the existing `accounts_users`), columns `user_id`, `account_id` typed like the referenced ids (`columnType()` reads `SHOW COLUMNS`), constraints `fk_<pivot>_<column>`, auto-created with `CREATE TABLE IF NOT EXISTS`; also sets `$this->pivot->accounts` (`->all` holds the joined rows).
- Relationship methods must be called on a loaded model (`$user = $this->find(1); $user->accounts();`). The calling method name is pushed into `__restricted` so it is not saved as a column.

## Database (`Caligrafy\Database`)

```php
Database::connect(): ?PDO                 // only when DB_ACTIVATE == 'true'; DSN from Database::dsn()
Database::dsn($adapter, $host, $dbName, $port = null): string   // "mysql:host=H;port=P;dbname=D"; port omitted when empty or when $host already contains "port="
Database::execute($query, $args = array()): array   // prepare + execute with bound $args; returns array of associative arrays
Database::toArray($result): array
Database::lastInsertId()
Database::is_Json($string): bool
```
- 2.3.0+: on MySQL, `connect()` runs `SET time_zone = '<date('P')>'` (PHP's `SERVER_TIMEZONE` offset) so `NOW()`, `CURRENT_TIMESTAMP` and the audit log (`Audit::record()` writes PHP `date()`) share one clock; `DB_TIMEZONE=server` skips it (`Database::alignTimeZone()`).
- PDO uses native prepares (`ATTR_EMULATE_PREPARES` false). Without an active connection `execute()` throws `[ERROR 2003]`.
- Safe custom query in a model method:
```php
use Caligrafy\Database;
public function findByEmail($email) {
    $rows = Database::toArray(Database::execute('SELECT * FROM ' . $this->table . ' WHERE email = ? LIMIT 1', [$email]));
    return !empty($rows[0]) ? $this->arrayToModel($rows[0]) : null;
}
```

- Also: `Database::table($table): Query` (see Queries), `Database::transaction(callable $fn)` (begin, run, commit; rollback and rethrow on any `Throwable`; returns what `$fn` returns; a call inside another one, or inside a transaction already open on the connection such as a test's, just runs in it; no connection -> `[ERROR 2003]`), `Database::rowCount()` (rows changed by the last statement), `Database::useConnection(?PDO)` (another PDO, e.g. an in-memory SQLite in a test; null connects again on next use).

## <a name="queries"></a>Queries (`Caligrafy\Query`, `framework/core/Query.php`)

```php
use Caligrafy\Database;
$rows  = Database::table('books')->where('price', '<', 20)->orderBy('title')->limit(10)->get();   // arrays
$books = Book::where('author_id', 3)->with('author', 'tags')->paginate(20);                       // Book models
```
- Values are always bound (`?`). Table/column names must match `/^[A-Za-z_][A-Za-z0-9_]*(\.[A-Za-z_][A-Za-z0-9_]*)?$/` and are backtick-quoted (`books.title` -> `` `books`.`title` ``); anything else -> `InvalidArgumentException` code 2001, before any SQL runs. Operators: `= != <> < > <= >= like "not like"` (case-insensitive); directions `asc|desc`; limit/offset whole numbers >= 0. A `Query` is mutable: each method returns `$this`; `first()`, `find()`, `value()`, `count()`, `exists()`, `paginate()`, `chunk()` work on a copy.
- Building: `select(...$cols)` (or one array; `'*'`, `'books.*'`, `'price as cost'`), `where($col, $value)` (=), `where($col, $op, $value)`, `where([$col => $value, ...])` (AND, in parentheses), `where(function (Query $q) {...})` (a group in parentheses), `orWhere(...)` (same forms), `whereIn($col, array)` (empty -> `0 = 1`), `whereNotIn($col, array)` (empty -> no condition), `whereNull($col)`, `whereNotNull($col)`, `whereBetween($col, [$from, $to])`, `search(array $cols, $keywords)` (`(c1 LIKE ? OR c2 LIKE ?)` with `%keywords%` bound, `\ % _` escaped with `\` (MySQL's default escape); empty keywords -> no condition; the whole trimmed string is one phrase), `orderBy($col, 'asc'|'desc')`, `latest($col = 'created_at')`, `oldest($col = 'created_at')`, `limit($n)`, `offset($n)` (without a limit -> `LIMIT 9223372036854775807 OFFSET n`), `input(array)` (where `paginate()` reads `page`), `models($class = Model::class)` (hydrate through the model's `arrayToModel()`), `arrays()`.
- Null: `where('col', null)` -> `IS NULL`, `where('col', '!=', null)` -> `IS NOT NULL`; another operator with null, or an array value -> `InvalidArgumentException` (use `whereIn`). Booleans are bound as 0/1, `DateTimeInterface` as `Y-m-d H:i:s`.
- Reading: `get(): array` (rows, or models), `first()` (`LIMIT 1`, null when none), `find($id, $col = 'id')`, `value($col)` (first row's value or null), `pluck($col, $keyCol = null)` (`array_column`), `count(): int` (`COUNT(*)`, order/limit ignored), `exists(): bool` (`SELECT 1 ... LIMIT 1`), `paginate($perPage = 20, $page = null)` -> `['data', 'total', 'page', 'per_page', 'pages']` (`$page` null -> `input()['page']` or `$_GET['page']`; anything but an int >= 1 is 1; `pages` >= 1; a page past the last returns `[]` without a second query; `$perPage` < 1 -> exception), `chunk($size, callable $fn($rows, $chunkNumber))` (ordered by `id` unless an order is set; `$fn` returning false stops -> false), `toSql()`, `getBindings()`. On `Book::query()` the rows are `Book` models even with `select()`: the columns not selected are the class's `null` properties and REST/CSV show them; `->arrays()` (or `Database::table()`) gives only the selected columns (G138).
- Writing: `insert(array $row)` or `insert([$row, $row])` (one statement, every row the same columns; arrays/objects as JSON) -> last insert id; `update(array)` -> rows changed; `delete()` -> rows deleted; `increment($col, $n = 1, array $extra = [])`, `decrement(...)`. `update`, `delete`, `increment` and `decrement` need a `where...()`: without one -> `LogicException`, nothing runs (use `Database::execute()` for a whole table). ORDER BY/LIMIT are kept on UPDATE/DELETE (MySQL).
- Eager loading: `with('author', 'tags', 'author.country')`, `with(['author' => ['table' => 'people', 'foreign_key' => 'writer_id']])`, `with(['books' => function (Query $q) { $q->where('published', 1); }])`, `withCount('books')` (adds `books_count`, one `GROUP BY` query). One query per relation, `WHERE <key> IN (...)` with the unique non-null keys (one per 1000 keys), none when there are no keys; the rows go under the relation's name: `null` / `[]` when none. Never a join that repeats the main rows.
  - Conventions (`Query::relation($parentTable, $name, $settings)`; `Query::plural()`: +s, consonant+y -> ies, s/x/z/ch/sh -> es; `Query::singular()` the inverse): a singular name (`author` on `books`) is belongsTo: `books.author_id` -> `authors.id`; a plural name (`books` on `authors`) is hasMany: `books.author_id` = `authors.id`; `['pivot' => true]` or `'type' => 'belongsToMany'` (`tags` on `books`): the pivot `Model::belongsToMany()` creates: `books_tags` (`<this table>_<related table>`), or `tags_books` when only that one exists (tried when the query on `books_tags` fails, then remembered for the process; when both fail the first error is thrown), `books_tags.book_id` = `books.id`, `books_tags.tag_id` = `tags.id`, one `INNER JOIN` of the pivot; `'pivot' => 'name'` uses that name as is.
  - Settings: `type` (`belongsTo|hasOne|hasMany|belongsToMany`), `table`, `foreign_key` (belongsTo: on the parent; hasMany/hasOne: on the related table; belongsToMany: the pivot column toward the parent), `local_key` (default `id`), `owner_key` (default `id`), `pivot` (`true` or a name), `related_key` (pivot column toward the related table), `query` (a function constraining the relation's query; also the value itself when it is a function). An unknown setting or bad name -> `InvalidArgumentException`.
  - Related rows are arrays (also under models); a nested relation applies to the related table (`author.country` -> `authors.country_id`).
- Models: `Book::query()` (models of Book on its table: `protected static $tableName`, else the default of `public $table`, else the short class name lower-cased + plural: `Book` -> `books`, `Category` -> `categories`; read once per class), and `Book::find($id)`, `Book::where(...)`, `Book::with(...)`, `Book::paginate(...)`, `Book::count()`... forwarded by `__callStatic` to `query()` (`select where orWhere whereIn whereNotIn whereNull whereNotNull whereBetween orderBy latest oldest limit offset with withCount first value pluck count exists paginate chunk get insert input arrays`). The same names on an instance (`$model->where(...)`) query the instance's `$table`. The instance `find()`, `all()`, `search()`, `create()`, `update()`, `delete()` are unchanged. An unknown method still throws `Error` "Call to undefined method".
- `Query::useExecutor($executor)` sends the builder's queries to an object with `execute($sql, $bindings): array` (+ optional `lastInsertId()`, `rowCount()`) instead of `Database` (tests); null goes back.
- N+1 detection: in development (`APP_ENV` not `production`, decided once per process: `Query::watching()`), `Database::execute()` and the builder count each SELECT by its shape (`Query::shape()`: literals and numbers -> `?`, IN lists folded, lower case); at the 10th identical shape (`Query::$threshold`) one `error_log` warning "Probable N+1 query ... from <file>:<line>" names the first caller outside `framework/` and suggests `with()`. `Query::watch(true|false|null)` forces it and resets the counts; `Query::forgetShapes()` (2.19.0) resets the counts only (`Testing\TestCase::setUp()` calls it); `Query::$logger` (callable) replaces `error_log`. Production: one static check per query.
- Speed: no reflection per query; identifiers are validated once per name and cached. `php qa/bench-query.php` (not part of the QA run) builds 10,000 queries: a few microseconds each.

## Validator (`Caligrafy\Validator extends \GUMP`)

```php
check($data, $rules = array(), $filters = array())
//  rules + filters: GUMP::run() -> the FILTERED DATA ARRAY on success, the errors array on failure (both arrays!)
//  rules only:      true, or ['field' => 'message']
//  filters only:    filtered data array
//  neither:         true
// GUMP methods available on $this->validator:
validate(array $input, array $ruleset)         // true or raw error list (Controller::validate() converts to field => message)
filter(array $input, array $filterset)
run(array $data, $check_fields = false)
get_errors_array(); get_readable_errors(bool $convert_to_string = false, ...);
GUMP::is_valid(array $data, array $validators, array $fields_error_messages = [])   // static; true or readable (HTML) error strings

```
Rule syntax: `'field' => 'required|max_len,100|valid_email'`, `'image' => 'required_file|extension,png;jpg'`. Filters: `'field' => 'trim|sanitize_string|lower_case'`.
- Framework rules (2.19.0, `Validator.php`): `exists,<table>.<column>` and `unique,<table>.<column>[,<ignoreColumn>,<ignoreField>]` registered once with `GUMP::add_validator` by the first `new Validator()` (`Validator::registerRules()`; a rule of that name the app added first is kept), checked with `Validator::exists($params, $value)` / `unique($params, $value, $input)`: `(new Query($table))->where($column, $value)->exists()`, unique adding `where($ignoreColumn, '!=', $input[$ignoreField ?: $ignoreColumn])` when that input is a non-empty scalar; table checked with `Query::quote`, column with `Query::NAME` (`InvalidArgumentException`/2001 otherwise, never sent). `Validator::normalize($rule)` (called by `validate()`, so `run()`, `check()` and `Service::validate()`): extra `,` arguments of `unique`/`exists` joined with `;` (GUMP's `parse_rule` keeps one `,`), `min_numeric,current_year` / `max_numeric,current_year` -> `date('Y')` at validation time. `get_errors_array()`: "There is no such <singular of the table, _ as spaces>" / "This <column> is already used" unless `GUMP::set_error_message()` or a per-field message replaced it. Empty optional inputs are not checked (GUMP). A GUMP rule with several parameters separates them with `;` (`word_count,min;10;max;500`, `between_len,3;10`): with `,` only the first one is read and `word_count,min,10,max,500` always passes (G139). Custom rules (`GUMP::add_validator($rule, callable($field, $input, $params, $value), $message)`) go in a file of `application/` outside `config/` and `views/` (e.g. `application/rules/<name>.php`): `config.php` is not loaded by the CLI (`call`, the scheduler, the queue), G141.

## FaceLogin (`Caligrafy\FaceLogin`, server side of `FaceDetector.liveness()`)
Static. `CHALLENGES = ['turn-left', 'turn-right', 'smile']` (no `blink`). `challenge($username = null, $count = null, $ttl = null)` (null: static `$count` 2, `$ttl` 60) -> `['nonce' => 64 hex, 'challenges' => [$count of CHALLENGES, random order, capped at 3], 'expires_in']`, kept in `$_SESSION['__face_challenge']` (replaces the previous one). `consume($nonce, $username)` removes it and throws `FaceLoginException` 401 (unknown/used, expired, other username). `verify($response, $username)` = consume + liveness (`passed === true`, passed challenges equal to the requested ones in order) + `checkPrints($prints)` (count `$minPrints` 3..`$maxPrints` 12, 128 finite numbers each or `['descriptor' => ...]`, pairwise `>= $distinct` 0.001 and `< $spread` 0.6; 422) -> `[[128 floats], ...]`. `match($prints, [['user' =>, 'descriptor' =>], ...])` -> `['user', 'distance']` (mean < `$match` 0.5, max < 0.6) or null. `enrolledElsewhere($prints, $enrolled, $user)`, `printHash($descriptor)` (sha256 of 5-decimal values), `descriptor($d)`, `distance($a, $b)`. `$clock` callable for tests.

| 1004 | Access Denied: <why> | JSON request to a controller route or `Route::action` (2.21.1, `GET` included) with neither the session's `X-CSRF-Token` (2.7.0+) nor, with `Auth::activateAPI()`, a valid `Authorization: Bearer` (token granting `*`, legacy key) |
| 2001 | Database Security Error | invalid column name given to `search()` or a Model write |
| 2003 | Database Query Error | `DB_ACTIVATE` not `true`, bad credentials/host, or SQL that fails to prepare |
| 3000 | Cross Site Forgery | form POST/PUT/DELETE without `_token`, or a non-JSON fetch/axios call |
| 4000/4001 | Mail errors | |
| 5000 | Key generator error | |

Errors are caught in `web.php` by `Errors::handle($e)`: HTTP status from `Errors::status($code)` (1001 → 404, 1004 → 401, 1005 → 404 Page Not Found and 1006 → 403 Forbidden (2.5.0, raised by `PageController`), 3000 → 403, 1000 → 405, anything else → 500), the `[ERROR ...]` text for HTML requests and `{"error": {"code": ..., "message": "..."}}` (prefix removed) when the request wants JSON. `Errors::raise($code)` (used by the router and the CSRF check) sets the status and returns the exception, so the status is right even with an old `web.php` that only echoes. `Framework::run()` buffers output (`ob_start` 1 MB chunks), and registers `Errors::shutdown` (PHP fatals → 500, partial page discarded) and an exception handler (uncaught `Throwable` → 500); their message is only shown when `APP_DEBUG=true`, otherwise `[ERROR 500] Internal Server Error`. Before this fix every error was HTTP 200.
