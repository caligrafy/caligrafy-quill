# 9.8.2 Routing for Single Page Applications

> Source: Caligrafy Quill wiki - https://github.com/caligrafy/caligrafy-quill/wiki/9.8.2-Routing-for-Single-Page-Applications
> Bundled with the caligrafy-quill Claude plugin. Content preserved from the wiki; formatting cleaned.

A single page app has one HTML page, and shows a different screen for each address: `#/` the list of the books, `#/books/3` one book. **Vue Router** maps each address to a page component; the page then asks the server for its data through the generated client. Caligrafy's server still answers the data (`Route::capabilities`) and serves the built app; the routes between screens live in `src/router/index.js`.

## With Claude

Ask for the screens and their addresses: "in shelfapp, the list of the books at #/ and one book at #/books/:id, each title a link". Claude writes the routes in `public/shelfapp/src/router/index.js`, the page components in `src/components/pages/`, and keeps hash addresses and the `:key` on `<router-view>`.

**Check** before you say OK:
+ The router uses `createWebHashHistory()`.
+ `App.vue` has `<router-view :key="$route.fullPath">`.
+ From one book, opening another (`#/books/1` then `#/books/3`) shows the second book.
+ A reload of `#/books/3` in the built app shows the same book.

## By hand

You give the Bookshelf app of [Setting up the Vue application](https://github.com/caligrafy/caligrafy-quill/wiki/9.8.1---Setting-up-the-Vue-application) two screens. Files are in `public/shelfapp/`.

**1. The routes.** The template's router already uses hash addresses (`createWebHashHistory()`, 2.19.1); give it the two screens. Replace `src/router/index.js` with:
```js
import { createRouter, createWebHashHistory } from 'vue-router'
import BooksPage from '../components/pages/BooksPage.vue'
import BookPage from '../components/pages/BookPage.vue'

const router = createRouter({
  // #/books/3: works with npm run dev and in dist/, from any folder, and survives a reload
  history: createWebHashHistory(),
  routes: [
    { path: '/', name: 'books', component: BooksPage },
    { path: '/books/:id', name: 'book', component: BookPage, props: true }
  ]
})

export default router
```
`:id` is a parameter of the address; `props: true` gives it to the page as the prop `id`.

**2. The list.** Write `src/components/pages/BooksPage.vue`:
```vue
<template>
	<main>
		<section class='cq-hero cq-hero--page'>
			<h1 class='cq-display'>Books</h1>
			<p class='cq-lead'>{{ total }} books on the shelf.</p>
		</section>
		<section class='cq-band cq-band--tight'>
			<div class='cq-inner cq-inner--narrow'>
				<p class='cq-alert cq-alert--error' role='alert' v-if='error'>{{ error }}</p>
				<ul class='cq-rows' v-if='books.length'>
					<li class='cq-row' v-for='book in books' :key='book.id'>
						<div class='cq-row-main'>
							<p class='cq-row-title'>
								<router-link :to='{ name: "book", params: { id: book.id } }'>{{ book.title }}</router-link>
							</p>
							<p class='cq-row-meta'>{{ book.author.name }}, {{ book.published_year }}</p>
						</div>
					</li>
				</ul>
				<p class='cq-empty-state' v-else>No books yet.</p>
			</div>
		</section>
	</main>
</template>

<script>
import { listBooks } from '@/capabilities.js'

export default {
	name: 'books-page',
	data() {
		return { books: [], total: 0, error: '' }
	},
	async mounted() {
		try {
			const page = await listBooks({ page: 1 })   // { data, total, page, per_page, pages }
			this.books = page.data
			this.total = page.total
		} catch (e) {
			this.error = e.message
		}
	}
}
</script>
```

**3. One book.** Write `src/components/pages/BookPage.vue`:
```vue
<template>
	<main>
		<section class='cq-hero cq-hero--page'>
			<h1 class='cq-display'>{{ book ? book.title : 'Book' }}</h1>
			<p class='cq-lead' v-if='book'>by {{ book.author.name }}, {{ book.published_year }}</p>
		</section>
		<section class='cq-band cq-band--tight'>
			<div class='cq-inner cq-inner--narrow'>
				<p class='cq-alert cq-alert--error' role='alert' v-if='error'>{{ error }}</p>
				<p v-if='book'>{{ book.summary || 'No summary yet.' }}</p>
				<p><router-link class='btn btn-secondary' :to='{ name: "books" }'>All books</router-link></p>
			</div>
		</section>
	</main>
</template>

<script>
import { getBook } from '@/capabilities.js'

export default {
	name: 'book-page',
	props: ['id'],
	data() {
		return { book: null, error: '' }
	},
	async mounted() {
		try {
			this.book = await getBook({ id: this.id })   // the book, with its author in book.author
		} catch (e) {
			this.error = e.message
		}
	}
}
</script>
```

**4. The frame.** Replace `src/App.vue` with (the template's, plus the `:key`):
```vue
<template>
	<show-navigation></show-navigation>
	<router-view :key="$route.fullPath"></router-view>
	<footer class='cq-footer'>
		<p>Copyright &copy; {{ new Date().getFullYear() }}</p>
	</footer>
</template>

<script>
import ShowNavigation from './components/global/ShowNavigation.vue'

export default {
	name: 'App',
	components: {
		'show-navigation': ShowNavigation
	}
}
</script>
```
The `:key` gives every address a fresh page: without it, going from `#/books/1` to `#/books/3` reuses the same `BookPage`, `mounted()` does not run again, and book 1 stays on screen.

**5. The top bar link.** In `src/components/global/ShowNavigation.vue`, the brand links to the old home: replace `:to='{ name: "home" }'` with `:to='{ name: "books" }'`. Then delete `src/components/pages/HomePage.vue` (nothing imports it any more).

**6. Try it.** Run `npm run build`, then open `http://localhost:8080/public/shelfapp/dist/index.html`:
+ The list says `5 books on the shelf.` and shows them sorted by title, each with its author and year; *A Wizard of Earthsea* links to `#/books/1`.
+ Click *Kindred*: the address becomes `#/books/3` and the page shows `Kindred`, `by Octavia E. Butler, 1979` and its summary.
+ Change the address to `#/books/1`: the page shows *A Wizard of Earthsea*. Reload: still the same book.
+ `#/books/999` shows `There is no book #999`.

**Check**
+ `npm run dev` gives the same screens at `http://localhost:5173/#/`.
+ The address bar never leaves `index.html`: every screen is after the `#`.

## Reference

| Part | Use |
| --- | --- |
| `createRouter({ history, routes })` | the router, installed by `app.use(router)` in `src/main.js` |
| `createWebHashHistory()` | addresses after a `#`: they work in development and in `dist/` from any folder, and survive a reload |
| `{ path, name, component }` | one screen; `name` lets links say `{ name: 'book', params: { id: 3 } }` instead of building the address |
| `path: '/books/:id'` | a parameter, read with `this.$route.params.id`, or as the prop `id` with `props: true` |
| `component: () => import('../components/pages/BookPage.vue')` | loads the page only when it is opened (a separate file in `dist/assets/`) |
| `<router-link :to="{ name: 'book', params: { id } }">` | a link between screens, without reloading |
| `this.$router.push({ name: 'book', params: { id } })` | goes to a screen from code (after a form, for example) |
| `<router-view :key="$route.fullPath">` | where the screen of the address appears, rebuilt for every address |
| `useRoute()`, `useRouter()` | the same in `<script setup>` components: `import { useRoute } from 'vue-router'` |

The server's routes and the app's routes are separate: `web.php` answers `/capabilities` and serves the files of `dist/`; the router chooses the screen from the part after `#`. See [Vue Router](https://router.vuejs.org/).

## Other ways

+ **Addresses without `#`** (`createWebHistory()`, the template's default before 2.19.1): `/books/3` works with `npm run dev`, but a reload asks the server for `/books/3`. The built app then needs its own site (a virtual host on `dist/` with `FallbackResource /index.html`, and `base` set to its path), or a reload answers `404`. Under `public/<app>/dist/`, keep hash addresses.
+ **Watching the parameter** instead of the `:key`: `watch: { id() { this.load() } }` in the page, when rebuilding the whole page is too much.

## Common mistakes

+ **A blank screen in `dist/`**: `createWebHistory()` with the app in a sub-folder (apps created before 2.19.1). Use `createWebHashHistory()`, as the template does since 2.19.1.
+ **The previous book stays on screen**: `<router-view>` without `:key="$route.fullPath"`.
+ **A route to a component that is not imported**: Vite stops the build (`Could not resolve`). Import every page the routes name, or use `() => import(...)`.
+ **Expecting `web.php` to know `#/books/3`**: the browser never sends the part after `#` to the server.
