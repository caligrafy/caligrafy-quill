# Security policy

## Supported versions

| Release | Security fixes |
|---|---|
| The latest minor (2.26) | yes, with every bug fix |
| The minor before it | for 12 months after the next minor shipped |
| Older minors | no |

There is no long-term support (LTS) release yet. The full policy:
[support and release policy](https://github.com/caligrafy/caligrafy-quill/wiki/Support-and-Release-Policy).

## Reporting a vulnerability

Please do not open a public issue. Report it privately:
[report a vulnerability](https://github.com/caligrafy/caligrafy-quill/security/advisories/new). The fix ships as a
patch release of every supported minor.
