# More design styles

Styles added to Caligrafy Quill outside the [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
collection of `framework/designs/`. They are kept in this separate folder so that `sh framework/designs/sync.sh`, which
mirrors that collection, never changes or removes them. `php caligrafer.php design list`, `design use <name>`, `doctor`
and `/caligrafy-quill:design` treat them like the other styles. A project's own `application/designs/<name>/` wins
over both folders.

| Style | Source | Added |
| --- | --- | --- |
| `interstellar` | "Interstellar" design system (laboratory operations software, website https://www.illumina.com; author in its front matter: Dov Azencot). Provided by the Caligrafy maintainer as `radiance-interstellar/DESIGN.md`, copied unchanged. The file states no license | 2026-10-31 |

The files describe a product's visual language to inspire a style; the names, logos and trademarks they mention belong
to their owners. A restyled application keeps its own name and logo. The production image leaves this folder out.
