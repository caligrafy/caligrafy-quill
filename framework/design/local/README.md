# Local design styles

Styles added to Caligrafy Quill itself rather than copied from a vendor collection. A local style wins over a vendor
style of the same name; a project's own `application/design/<name>/` wins over both
([framework/design/README.md](../README.md)). Add one as `<name>/DESIGN.md` and a row below saying where it came from.

| Style | Source | Added |
| --- | --- | --- |
| `interstellar` | "Interstellar" design system (laboratory operations software, website https://www.illumina.com; author in its front matter: Dov Azencot). Provided by the Caligrafy maintainer as `radiance-interstellar/DESIGN.md`, copied unchanged. The file states no license | 2026-10-31 |

The files describe a product's visual language to inspire a style; the names, logos and trademarks they mention belong
to their owners. A restyled application keeps its own name and logo.
